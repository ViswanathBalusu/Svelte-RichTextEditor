# 0354 Lane U-SYN-001-018: open code for an oversized or mistyped field value

**Status:** proposed (2026-11-13)

## Context

SYN-012 criterion 3 says that a commit giving a field value of more than 4 KiB, or a value of the wrong type for its kind, is refused with `invalid_op` (I15). SYN-012 Notes and SYN-012's P7 rule (`field_invalid` for a user who holds only `fill`) conflict for a wrongly typed value. The room answers `field_invalid` for an oversized value as well. The spec default is kept; the choice is left to FRW.

## Decision (proposed)

Keep the current behaviour (`field_invalid` for an oversized or wrongly typed value submitted by any user whose only violations are field values) until FRW confirms the code in 12 §4.2. The test `packages/authority/test/syn-012-i15-limits.test.ts` accepts either code and records the open point.

## Consequences

SYN-012 criterion 3 stays unticked until FRW decides and the rules limit (500 rules) is tested through the room.
