# ADR 0214: Lane PRO-043-056, round 3

Status: proposed (2026-11-13, lane PRO-043-056, round 3)

## Context

The lane owns the control-plane stories PRO-043 to PRO-056 in `docs/stories/PRO-protocol.md`. In round 3 the lane ticked two criteria of PRO-053 (region states). PRO-054, PRO-055 and PRO-056 (history, comparison, restore) have no route in `services/document-service` yet. The engines for them exist in `packages/history`.

## Decisions

1. Diff, attribution and restore wiring waits for a dependency. `services/document-service/package.json` does not list `@docedit/history`, so its routes cannot import the engines. The spec default is unchanged. Adding the dependency is a package.json change, which this lane may not make; the main session must decide it.
2. Named versions need a store. Named versions (PRO-054) have no table or store in `services/document-service/src/storage`. The store is a schema change and is for the main session or the storage owner to schedule.
3. PRO-053 criterion 1 stays open. The control commit for a region-state change is recorded by the room (07 §9), and no test asserts it for region states. The spec default is kept: the criterion is not ticked without that assertion.
4. PRO-053 criterion 6 is ticked on the owner-origin test and the existing editor and import tests. The spec (PRM-043) applies to every origin, and the tests cover the owner (a client commit) and an import; a commit by the server itself is not tested.

## Consequences

- PRO-054, PRO-055 and PRO-056 stay unticked, each with a Note in its story.
- No root configuration or package.json file was changed.
