# ADR 0318: Lane U-EXP-017-032, round 2 (proposed)

Status: proposed. Date: 2026-11-13. Scope: stories EXP-017 to EXP-032 in `docs/stories/EXP-export.md`.

## Context

Round 2 closes criteria that earlier lanes left unticked because they needed a compile, Podman or a browser. Three stories were worked: EXP-025 (criterion 3, corpus text), EXP-029 (criterion 3, footnote continuation in `layout.json`) and EXP-032 (criterion 1, tab stops and leaders). The sandbox readiness probe was checked for the leftover from the last review.

## Decisions taken here (spec default, owner to confirm)

1. The corpus for EXP-025 criterion 3 is written in its test file. The shared `packages/corpus` set is not used, because it is not a text-run corpus. Spec default kept: the criterion names "the corpus" without defining it. Owner to name the corpus if the shared set should be used.
2. The sandbox readiness probe (`services/export-worker/src/sandbox-ready.ts`) decides "host mounts" by whether `/run/secrets` holds any entry. An empty overlay therefore passes, as the last review asked. It does not check the mount itself. A host directory that is empty would also pass. Proposed follow-up for the owner of SEC-048 and EXP-072: read `/proc/self/mountinfo` for `/run/secrets` and require a `tmpfs` entry. Not changed here, because the file belongs to another lane.

## Environment findings (2026-11-13, this host)

- `podman info` took 74 to 106 s under the load of the parallel lanes. The probe's 30 s timeout (`container.ts`, `podmanInfo`) then reports Podman unavailable, and every sandbox test skips. The probe result depends on load, not only on configuration.
- Direct container start failed with `crun: controller pids is not available`. The machine route (`DOCEDIT_PODMAN_MACHINE=podman-machine-default`) starts containers.
- The EXP-029 and EXP-032 compile tests ran unskipped in one window of this round. The EXP-025 corpus test passed only with the readiness probe replaced in a scratch vitest config and the machine route set. The unmodified command must be run again when the probe passes.

## Needed from others

- Owner of `services/export-worker/src/container.ts`: the 30 s `podmanInfo` timeout is too short on a loaded host. Either a longer timeout or a cached result from a previous run is needed. Not changed here.
- Owner of `sandbox-ready.ts`: the mount check in decision 2.
- Owner of the sandbox image or host: a run of `packages/export-latex/src/exp-025-runs.corpus.compile.test.ts` with the unmodified command, once the probe passes.

## Round 8 (lane U-EXP-017-032, proposed)

Scope: stories EXP-022 and the blocked criteria found in EXP-017 to EXP-032. Only one story was worked to a decision; nothing new was ticked this round.

1. EXP-022 criterion 2 (backslash in a bookmark). Cause found in the compiled PDF: hyperref takes the outline title from the typeset content, and the converter's plain form (`\DEstr` in argument 4 of `\DEh`) is not used for it. Wrapping the content in `\texorpdfstring` gave a raw backslash in the UTF-16 literal, which is read as an escape. That change was reverted. Owner or next round to choose the escape route. `it.fails` stays. Spec default kept.
2. EXP-030 criteria 1 and 5 are emitter decisions, not changed here. Spec default for criterion 5 is one string emitter for link titles (`pdfString`); changing it needs a class change in the link socket (`class/docedit.cls`, `\DE@linkcontents`), because `pdfString` yields `\DEstr{hex}`, which is not a PDF string in a dictionary entry. Spec default for criterion 1 (percent-encode `&`, `#`, `%`) would change valid URLs; owner to decide (see the round 14 note in the story).
3. EXP-021 criterion 5 and EXP-032 criterion 4 need the shared fixtures of EXP-115. EXP-115 is outside this lane's range (`docs/stories/EXP-export.md`), so it is listed for the main session.
4. EXP-023 criterion 4 needs EXP-062 (outside range), and EXP-028 criterion 3 needs the owner's decision on whether `align` moves the caption (ADR 0223, decision 12).
