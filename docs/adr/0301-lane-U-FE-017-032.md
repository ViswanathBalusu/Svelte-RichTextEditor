# ADR 0301: Lane U-FE-017-032 decisions (proposed)

Status: proposed. Date: 2026-11-13.

## Context

Lane U-FE-017-032 closes the criteria in FE-017 to FE-032 that earlier lanes left open for want of a browser, a container or a change in another package. Owner decisions stay with the owner.

## Decisions taken in this lane

1. **FE-021 criterion 2 overlay.** The overlay the shell has is the context menu (`packages/ui/src/components/ContextMenu.svelte`). Its items are the focus target in the browser test. Tooltips and dialogs are not covered by this decision.
2. **FE-020 criterion 1.** Ticking is limited to the menu. The criterion names menus, tooltips and dialogs; the tooltip and dialog parts stay open until they are opened in a browser.
3. **FE-020 criterion 2 (Popover fallback).** Left open. Deleting `showPopover` in a script does not reach the fallback, because the browser's stylesheet still hides `[popover]` elements that are not open. A real browser without the API is needed.
4. **FE-026 criterion 7.** The UI's `CoreApi` (`packages/ui/src/core-api.ts`, described there as what the UI sees of the core) is taken as the document API for this criterion. The stub is `packages/ui/test/support/fake-core.ts`.
5. **Test ports.** Browser runs used port 56010 through `DOCEDIT_DEMO_PORT`, because the default port 4791 is shared, and `reuseExistingServer` in `packages/element/playwright.config.ts` would attach to another agent's server.

## Open for the owner or the main session

- FE-026 criterion 1: the dependency rule must match module names as well as resolved paths (see FE-026 Notes). Root configuration.
- FE-020 criterion 3: Floating UI is not a dependency of `packages/ui`. Adding it is a dependency decision.
- FE-032 criterion 5: the spec's default for select-all inside a region (whole body) is not recorded as a decision in the Open questions. The conflict between 02 §5.2 and 07 §7 is the owner's.
- Shared Playwright output: `packages/element/playwright.config.ts` writes traces to a directory shared by all runs; parallel runs fail with ENOENT on trace copies. A per-run output directory would remove this.

## Round 4 (2026-11-13)

Stories not handled in earlier rounds of this range: FE-022, FE-024, FE-027, FE-030 and FE-031. Every criterion in each is already ticked in `docs/stories/FE-frontend.md`, so this round changed no story and ran no test.

Unticked criteria left in the range are all in stories handled in earlier rounds (FE-017, FE-018, FE-019, FE-020, FE-023, FE-026, FE-029), or wait for the owner or the main session (FE-032 criterion 5, FE-020 criterion 3, FE-026 criterion 1). They are not reopened here.
