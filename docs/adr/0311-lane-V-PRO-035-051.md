# ADR 0311: lane V-PRO-035-051 (round 2) decisions and open questions

Status: proposed (lane record; no owner decision taken)

Date: 2026-11-13

## Context

Lane V-PRO-035-051 closed blocked criteria in stories PRO-035 to PRO-051 by running tests against
the real environment or against another package. Round 2 worked from PRO-051 downwards (PRO-051,
PRO-050, PRO-049 and PRO-046 had nothing open for this lane). Three stories moved: PRO-044, PRO-037
and PRO-039. Four points needed a decision or are a mismatch the lane could not settle.

## Decisions taken (spec default)

1. A `ch.closed` with `internal` suspends the channel with backoff, as `unavailable` does. The
   registry gives `internal` the client action "Back off." (PRO-038, `packages/protocol/src/definition/errors.ts`).
   Before this lane the protocol client ended the channel on `internal`
   (`packages/protocol/src/client/channel.ts`, `onClosed`). The change is one condition and a
   comment. Tests: `packages/backend-dep/test/pro-039-backoff.test.ts`, and the existing channel
   and resume tests (31 tests passing).

2. `startService` now forwards its `onSpan` option to the data plane's settings
   (`services/document-service/src/server.ts`, one line). Before this, the data plane's spans never
   reached the caller's sink in the composed service, so traces of a WebSocket session were lost.
   This is a bug fix, not a policy choice.

## Open questions (not decided here)

A. PRO-037 criterion 4: a frame above eight times `maxMessageBytes` is cut by the WebSocket layer
   with close code 1009, which is not one of the nine codes. ADR 0035 must map it, or the
   criterion must change. Owner or ADR 0035 owner to decide. Criterion left open.

B. PRO-039 criterion 6: `packages/backend-dep/src/connection.ts` (the `fatal` branch) closes with
   `bad_message` and reconnects with backoff when the client itself finds a malformed server frame.
   The criterion says a `bad_message` or `unknown_type` that arrives is reported through `de-error`
   and not retried. Whether the self-detected case should retry is not stated. The `de-error`
   report is in the element package, not built here. Criterion left open.

C. PRO-048 criterion 3: no client code in the repository reads `GET /documents/{id}` metadata
   (`packages/backend-dep` reads content, regions, grants, commits and assets only). A test that
   "a client ignores an unknown classification field" needs such a read to exist first. Criterion
   left open; the client read is a feature, not a test gap.

D. PRO-037 criterion 3 says "the kit triggers each one". The conformance kit (PRO-108) is not
   built. The nine codes are triggered by the service's own tests (see the story's Evidence), and
   PRO-108 is to run the same triggers. The owner may decide whether the parenthetical makes the
   criterion depend on the kit; the lane ticked it on the service's tests.
