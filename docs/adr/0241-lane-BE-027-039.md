# ADR 0241: Lane BE-027-039 open questions (proposed)

Status: proposed. Owner: the main session.

## Context

Lane BE-027-039 (round 1) found a question the spec and ADR 0034 leave open. Per the repository rules it is recorded here and not decided.

## Question

When a resume is beyond `catchUpCommits` and the host serves the commits resource, ADR 0034 §3 says the room answers `page`. The gateway (`packages/authority/src/projection/gateway.ts`, `ch.opened`) turns every `page` into `reload` for the channel, so the data plane answers `reload`. BE-038 criterion 4 says the channel's answer is `reload`, which matches the code.

## Options

1. Keep the code (`reload` always) and amend ADR 0034 §3 to say so. This follows the story as written.
2. Serve `page` to readers whose class carries no hidden steps, as ADR 0034 §3 describes. This needs the gateway change and a test.

## Default used

Option 1 is what the code and BE-038 criterion 4 do today. Nothing has been changed.
