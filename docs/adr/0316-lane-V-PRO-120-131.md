# ADR 0316: decisions of lane V-PRO-120-131 (round 2)

Status: proposed. Written by the lane, not by the owner. The owner may confirm or change any item.

Context: PRO-131 criterion 1 needs the leak oracle to read exports and asset URLs as well as frames and REST responses. Only the export worker's handler (services/export-worker/src/job.ts) builds exports, and the reference process runs no handler (reference.test.ts known defect `exports.states`).

## Decisions

1. The `perm-read` leak scenario requests a `cdm` export (not `pdf`), because the CDM target needs no sandbox compile and shows the projected envelope directly. The owner's export is requested first and is awaited for up to 60 seconds. It must deliver the confidential region, which makes the canary real in exports.
2. Readers without access have their exports requested. They are awaited only when the owner's export was delivered. Otherwise the request is only sent, so the scenario does not wait on a queue that is not served. The report notes each reader's outcome (`delivered and scanned`, or the state it ended in).
3. When the owner's export is not delivered, the leak scenario still passes, and its note says `export branch unproven`. The criterion for exports is then not proven for that service, and the story stays honest about it.
4. The export branch test (`services/document-service/test/postgres/pro-131-perm-read-exports.pg.test.ts`) runs the service on PostgreSQL and the shared S3-compatible store, with the export worker's real handler in the same process. Its tenant, database and objects are its own (names carry `V-PRO-120-131`) and are removed afterwards. It sets `DOCEDIT_CONTAINER_CGROUPS=disabled` for its own run, because the font manifest read is a `podman run` and this WSL Podman needs `--cgroups=disabled` (infra/test-env.ps1). It reads the font manifest once before the service starts, with three attempts.
5. The kit's leak scenario timeout is 240 seconds (it was 120 seconds), to allow the owner's export wait.

## Not decided here

- Whether a service without an export handler should announce `exports` on PostgreSQL (ADR 0054 default). This lane did not change it.
- Whether the kit should fail, rather than pass with a note, when exports are announced but not delivered. The owner decides; the spec default (pass with the note) is kept.
