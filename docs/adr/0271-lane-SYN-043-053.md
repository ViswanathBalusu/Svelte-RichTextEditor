## Questions

1. **Scope of the no-op rule for unappliable confirmed steps (SYN-045 criterion 1, 04 §14).** The spec says "every client MUST" and does not limit the rule to relay channels. Default taken: the rule applies on every channel, as `packages/engine/src/sync/state.ts` (`applyConfirmed`) already does; the engine has no channel kind to limit it by. Owner: the spec (04 §14) and the maintainer of SYN-043, who would prefer a native channel to stop on such a step so that the divergence check catches the engine bug.
2. **Test hook for a step applied differently (SYN-043 criterion 5).** The criterion needs a hook that makes one client apply a step differently. The engine exposes none. Default taken: unticked; the session tests reach the reload with a wrong hash, which is not the same thing. Owner: the engine maintainer, to name a hook.
3. **Room choice to send `sync.check` (SYN-043 criterion 1).** The spec does not say when the room chooses a checkpoint. Default taken: unticked; the message and its hash exist (`packages/authority/src/room/check.ts`). Owner: the spec (04 §13) and the authority owner.
4. **Reporting channel for a divergence (SYN-043 criterion 3).** The spec leaves open where a diverged client reports the event (Open questions of the story file). Default taken: the engine's `report` event with code `divergence`, shown through `DocumentCore.problem`, not fatal. Owner: UX and the spec.
5. **Mock and local backends in the skip test (SYN-045 criterion 2).** Running the same unappliable step through `packages/backend-mock` and a local backend needs the conformance harness. Default taken: unticked. Owner: PRO (PRO-111) and BE.
6. **Relay documentation and the `core-relay` profile (SYN-044 criteria 4 and 5).** The integrator documentation is outside this lane and the conformance profile is PRO-111. Default taken: unticked. Owner: PRO and the documentation owner.
7. **Live `Room.open` engine argument (SYN-046 criterion 4).** `EngineRegistry.negotiate` exists, but `Room.open` takes no engine argument, and no DEP gateway calls it yet. Default taken: unticked. Owner: the authority owner and PRO.
8. **Reference machine for projection cost (SYN-050 criterion 4).** The cost per class needs the reference machine (FND-007). Default taken: unticked. Owner: FND.
9. **Gateway ProseMirror types (SYN-046 criterion 2).** `src/projection/gateway.ts` imports ProseMirror types. Default taken: unticked. Owner: the authority owner.

## Consequences

Each question above has its own Note in the story file where a story is affected. Nothing else changes until the owners answer.
