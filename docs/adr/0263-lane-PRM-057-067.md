## Questions

1. **Owner decisions with no criterion ticked (PRM-061, PRM-063, PRM-064, PRM-065).** Each needs the owner's decision. The round 4 proposals in ADR 0146 still stand and are not repeated here: `everyone` on a restricted region (PRM-061); part of `structure` grantable per region (PRM-063); a per-region size quota (PRM-064); the identifier, grants, policy and state of split and merged regions (PRM-065). No code was changed for them. Default taken: none; the spec does not name one for PRM-061 and PRM-065.
2. **Block-level suggestion scope (PRM-062, criterion 4).** The `perm-suggest` profile scope and the amendment of PRM-013 and PRM-014 need the owner to change 07 and 03, and PRM-013 and PRM-014 belong to another lane. ADR 0146 proposes the scope. Default taken: none.
3. **Error code for control-plane refusals (PRM-066, criterion 2).** The criterion names `permission_denied`. The control plane answers `forbidden` for a grant change without `manage` (HTTP 403, "needs `manage` (07 §12)"), and the commit path answers `permission_denied`. Default taken: keep `forbidden` on the control plane and amend the criterion. Owner: the spec owner.
4. **`ch.open` with a revoked token answers `forbidden` (SEC-014, criterion 2 of `revocation.test.ts`).** `#openChannel` in `services/document-service/src/data-plane/session.ts` maps every failure of a channel token to `forbidden`. The test records this as `it.fails`, so it will flag when the service changes. PRM-060 criterion 6 only asks for a refusal, so it is ticked. Default taken: the service answers `forbidden` today. Owner: the data-plane owner, to decide whether `revoked` is required there.
5. **Activity surface (PRM-060, criterion 7).** Activity is not served; `history-routes.ts` lists it as outside the module. The criterion stays open until the route exists and the gate of section 8 is applied to it. No default needed.
6. **Math gate for oversized equations (PRM-060, criterion 1).** It is the math gate of EXP (09) and is not in this lane's packages. It stays open.
7. **Profiles `history`, `comments`, `exports`, `leases`, `perm-doc`, `perm-region` (PRM-057 and PRM-058, tagging criteria).** The profiles and the mock-backend run do not exist yet. Not in this lane's range for this round.
