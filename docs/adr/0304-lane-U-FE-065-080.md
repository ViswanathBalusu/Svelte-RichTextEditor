# ADR 0304: Lane U-FE-065-080 open questions (round 8)

Status: proposed. Owner: the main session. Lane: U-FE-065-080.

This record holds the questions that round 8 of the lane could not decide. Nothing here is decided
by the lane. Where a default is named, it is the spec's default or the lane's proposal, and it is
not in force until the main session accepts it.

## 1. FE-065 criterion 3: a change of `view` while the editor is open

Criterion: the editing core is not recreated and unconfirmed work is not lost.

Today `doc-editor.ts` ignores a change of `view` (its `default` branch in `attributeChangedCallback`).
Only the read view differs from the web view. Moving from `web` to `read` must end the editing
core, because the read view has no session (FE-072). The criterion cannot hold for that move unless
the session stays alive behind the read view.

Options:

- (a) Keep the session open while the read view shows; hide the editing surface. The journal and the
  core stay. Proposed default, because it is the only reading that meets the criterion as written.
- (b) Close the session when the read view opens, and reopen it (with the journal) when the view
  returns to `web`. Needs the journal to hold every unconfirmed commit, which FE-008 provides.
- (c) Refuse the change while there is unconfirmed work, and say so. An owner decision.

Not decided here. Criterion 3 stays unticked.

## 2. FE-078 criterion 2: offsets for every node of the layout tree

Criterion: any node records its block identifier and the document offsets it covers.

Paragraph fragments and lines carry `from` and `to`. Table fragments, box fragments, rows, cells
and pages do not (`packages/layout/src/tree.ts`). The open choice is what offsets a table, row,
cell, box or page covers (see also lane V-FE-065-080, item 2).

Proposed default: a table or box covers the CDM range of its own block in the flow document, from
the start of its first position to its end; a row or cell covers the range of its cell's blocks;
a page covers from its first fragment's start to its last fragment's end. This needs `FlowTable` and
`FlowBox` to carry a range, which they do not. The change crosses `flow.ts`, `tables.ts`,
`paginate.ts` and `tree.ts`, and every test that builds these nodes by hand.

Not done in round 8: the change is cross-package and touches shared tests that other lanes edit.
Criterion 2 stays unticked. Subtree identity (criterion 4) needs incremental layout (FE-088).

## 3. FE-080 criteria 1, 2 and 4: the Unicode line breaking algorithm

Criteria need a bundled implementation of UAX #14 and its test data for a named Unicode version.

- The repository holds no `LineBreakTest` data. The lane searched `node_modules/.pnpm` and found none.
- `linebreak@1.1.0` is in the pnpm store only as a transitive package. `@docedit/layout` does not
  declare it, and adding it means editing `packages/layout/package.json` and running
  `scripts/pnpm-locked.ps1`. The lane has no permission for either.

Needed from the main session: a decision on the dependency (or on a hand-written table), the
Unicode version to bundle, and the test data file. Criteria 1, 2 and 4 stay unticked.

## 4. FE-067 criterion 3: image sources

The engine draws an image mark as a `span` with no source. The element has no asset URL path yet
(PRO-091, FE-071 criterion 1). Criterion 3 needs that path, then a browser test that checks the
`src` is an asset URL, never `data:`, and that an SVG asset is not drawn as live SVG. Not built.

Criterion 5 (a fuzz corpus in every attribute) stays unticked. The seeded corpus of
`packages/element/e2e/fe-067-hostile-corpus.spec.ts` covers text, link href and title, and the
family and colour marks. It is not every attribute and it is not a coverage-guided fuzz run.

## 5. FE-073: printing from the element

Criteria 1, 2 and 4 need a host `print()` method and a viewer print path. Printing from inside the
viewer frame is refused by Chromium because the frame has no `allow-modals`, and FE-071 forbids that
keyword. The sandbox question is recorded in docs/adr/0304-lane-V-FE-065-080.md. Not decided here.

## 6. FE-066 criterion 1: the composition matrix

WebKit composition is skipped by design (a manual checklist, `s1-composition.spec.ts`), so the
criterion as written ("each supported browser") cannot close by an automated run. Firefox has
failures in the one-step commit and footnote groups from round 2. Left open.

## 7. KaTeX font directory (FE-069)

The session takes the directory as `katexFontsUrl`. No `config` member passes it, so a mounted
`<doc-editor>` registers no KaTeX font, and the element has no default location. The public name is
the main session's decision. The per-family alias proposal is in the FE-069 Notes. The KaTeX licence
is unverified.
