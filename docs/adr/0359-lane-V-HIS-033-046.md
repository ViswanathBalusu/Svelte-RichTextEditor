# ADR 0359: decisions of lane V-HIS-033-046 (proposed)

Status: proposed. Owner decisions stay the owner's; these are the spec defaults as implemented.

## 1. Erasing a person deletes their read markers (HIS-038 criterion 1)

Erasure deletes the `tenant_users` row (the display name goes with it) and then the `read_markers`
of the person's surrogate, in one transaction. The service role gets `delete` on `read_markers`
(migration `0061_his_038_erase_read_markers.sql`). Nothing in the log changes. Default taken: the
read markers are personal data (08 §13) and are deleted, not thinned.

## 2. The suggestion index is persisted (HIS-042 criterion 4, store part)

The introducing commit of each suggestion is kept in `suggestion_introductions` (migration
`0062_his_042_suggestion_introductions.sql`), keyed by tenant, document and suggestion identifier,
under row-level security. The lowest `seq` wins, as in `suggestionIndex`. The owner may choose
another table shape; the schema change is what HIS-042 Notes called open.

## 3. Migration number

Migration `0061_his_038_erase_read_markers.sql` shares its number with another lane's
`0061_workflow_sealed_pdf.sql`. The file names differ, so both apply; a later clean-up may renumber
one of them before the next release is listed in `releases.json`.

## 4. The chain head of an export at a seq (HIS-034 criterion 3)

The chain head of the state at `seq` is the stored hash of the commit at that `seq` (`doc_commits.hash`,
read by `PgLogStore.chainHeadAt`). At the head this is the head's chain head. The manifests of a
PDF export and of a bundle name it; a store that offers no lookup leaves it null. Default taken: the
spec does not say which hash an export at an older `seq` names; the commit's own hash is the one a
relying party can check with the verification tool (HIS-033), which walks the chain up to that seq.

## 5. Read restrictions are tested through the served routes only (HIS-046 criterion 5)

The negative test covers the routes the control plane serves (content, versions, activity, commits).
`diff`, `history`, `attribution` and `restore` are not served (HIS-026), so their answer is a 404 with
no content. The test names this and is to be extended when HIS-026 serves them. Default taken: a
region is hidden from a reader only when it is `confidential` (ADR 0019; `visibility.ts`); the fixture
of the test uses that policy.
