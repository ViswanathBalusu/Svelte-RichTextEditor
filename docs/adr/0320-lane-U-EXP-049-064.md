# ADR 0320: Narrow the math allow-list to what amsmath and the math font provide

Status: proposed (lane U-EXP-049-064, 2026-11-13). Owner review requested.

## Context

09 §6.3 says the allow-list is the intersection of what KaTeX supports and what `amsmath` and the
chosen math font provide, minus the commands the gate forbids. The generator
(`packages/export-latex/src/math/allow-list-source.ts`) only applied the KaTeX half. The class
(`packages/export-latex/class/docedit.cls`) loads `amsmath` and `unicode-math` and does not load
`amssymb`.

The compile test of EXP-049 criterion 5 (`packages/export-latex/test/math-allow-list.compile.test.ts`)
compiled every allow-list entry under the class in the export worker sandbox. The first run failed
on `\blacklozenge` with "Undefined control sequence".

## Measurement

A one-off compile printed `\ifdefined` and `\meaning` for all 503 allow-list commands under the
class (Podman, image `localhost/docedit-export-worker:s4`, 2026-11-13). It found:

- undefined: `blacklozenge blacksquare bm centerdot circlearrowleft circlearrowright degree
  doteqdot lozenge npreceq nshortmid nshortparallel nsucceq ntriangleleft ntriangleright shortmid
  shortparallel square varpropto`;
- base-LaTeX placeholders (`\not@base`, which fail when used): `leadsto lhd rhd unlhd unrhd`.

All 24 are symbols that `amssymb` defines (or `bm` and `\degree`, from packages the class does not
load).

## Decision (spec default)

Remove the 24 names from `candidates.ts`, and regenerate `allow-list.ts` with
`node packages/export-latex/scripts/math-allow-list.ts`. The fingerprint changes.

Alternative not taken: load `amssymb` in the class. That changes the math setup the spec names, and
the owner has not decided it. If the owner wants these symbols, the way is a class change plus a
new ADR. Then the candidates can be restored, and the compile test shows whether they compile.

## Consequences

- The gate refuses these commands. A document that uses one of them gets a `math_refused`
  placeholder at export (EXP-051 criterion 3). Whether any real document uses them was not checked.
- The compile test (EXP-049 criterion 5) passes on the narrowed list.

2. EXP-052 criterion 5 (clipping). `docedit.cls` does not clip equations to their box. A clip in

3. EXP-056 criterion 1 is blocked by a glyph gap, not by the layout code. The corpus document

   fatal "Missing character" error. Whether the converter should refuse or substitute such
   characters per block is EXP-026's decision; the test in
   `packages/export-latex/src/exp-056-layout-pdf.compile.test.ts` shows the failure.

## Round 3 review of the open stories (lane U-EXP-049-064, 2026-11-13)

No criterion was ticked in this round. Each blocker below is recorded here and stays open in its story.

1. EXP-061 criterion 4 (non-convergence at a job limit). Spec 09 §8 says the result records
   whether references converged. EXP-071 criterion 2 says a job that exceeds a limit ends `failed`
   with a diagnostic and no result. The two conflict for a final export that hits the wall-clock
   limit before it converges. Spec default proposed: keep EXP-071 (a limit ends the job `failed`),
   and treat "the pass cap ends the job unconverged" as the case that delivers a flagged result
   (already tested in `services/export-worker/src/job.test.ts`). Owner to decide.
2. EXP-053 criterion 2 (token stream and box containment). The lexical half is in
   `packages/export-latex/src/math/gate.fuzz.test.ts`. The trace half needs a tracing hook in the
   compile (the class and worker do not enable `\tracingcommands`). The box half needs a check of
   PDF content against the equation box, and the class does not clip to the box (see item 2 above).
   Criterion 5 (regression fixture) is conditional on a failure the fuzzer has not found.
3. EXP-058 (phase 3, form-field rectangles). `layout.ts` and the worker's layout parser have no
   `fields` member, and the class's Lua code reports no form-field rectangle. Building it changes the
   class and the schema. The unit and origin are not in the spec (09 §7.1, open question); the
   spec default is not stated, so criterion 3 needs an owner decision first.
4. EXP-062 criterion 3 (the viewer is told a preview is stale). The result carries the flag
   (`job.test.ts`), but `packages/element/src/features/pdf.ts` only shows a PDF and reads no export
   result. The export UI belongs to the FE lane.
5. EXP-054 (phase 2 spike). Needs the converter candidates installed (only through
   `scripts/pnpm-locked.ps1`, not run here) and a corpus of equations from real Word files, which
   does not exist in the repository.
6. EXP-057 (phase 3, line-level layout) needs line starts and table rows reported by the class's Lua
   code. EXP-063 is conditional on the EXP-060 measurement on the reference machine, which is not
   available here.

## Round 8 (lane U-EXP-049-064, 2026-11-13): EXP-059 (L2, forced first-fit breaks)

Status: proposed. Owner decision needed. Nothing is built and no criterion is ticked.

Question (09 §15, "Whether L2 is ever worth building"): whether the class should force the editor's
first-fit line breaks, giving up TeX's paragraph quality (09 §7 table, L2 row).

Evidence available to this lane: none that decides it. S4 (offset precision, 09 §15) has no
measurement on the reference machine (see EXP-060 Notes), and L1 has no adoption data in use. The
story asks the owner to decide on that evidence, so this lane makes no measurement-based claim.

Spec default used for now: L2 is not built. 09 §7 calls L2 experimental and 09 §15 keeps it open;
EXP-059 Notes say no implementation story is written unless the decision says build.

Options for the owner, with the reasons each one carries:

- Do not build. L0 and L1 stay the supported parity levels. Cost: none now. Risk: editors and
  exports keep differing on edited text.
- Defer. Keep the question open until S4 has a measured precision figure on the reference machine.
  Cost: the question stays open in 09 §15.
- Build as experimental. Requires the constraints of 09 §7 (same fonts, no hyphenation, fixed
  leading, breaks forced with penalties before TeX's line breaker runs) and an announcement that
  labels the mode experimental and states the loss of TeX's paragraph quality.

Owner decision: [ ] do not build  [ ] defer  [ ] build (experimental). Record the choice in the
story Notes of EXP-059 and in 09 §15.
