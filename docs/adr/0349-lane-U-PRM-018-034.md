# ADR 0349: Lane U-PRM-018-034 decisions (proposed)

Status: proposed. Owner decisions stay with the owner. Each item below is the spec default or the narrowest reading, and is listed so the main session can confirm or change it.

## 1. ETag of the region list (PRM-032 criterion 3)

The spec (05 §6.2) does not say how the list's ETag is formed. Default taken: the tag names the head (`incarnation` and `seq`), the reader's view token (as the content ETag does, D70) and the grants revision, so that it changes when a region is added or retired, when a grant or a region state changes, and when the reader's view changes. Implemented in `listRegions` (`services/document-service/src/control-plane/handlers.ts`), answered with 304 to `If-None-Match`. Not decided: whether the directory names in `editors.principals` should also move the tag (they do not today).

## 2. Client refresh after `permission_denied` (PRM-020 criterion 4) — not taken

Unchanged from ADR 0260. The engine emits `permissions-stale` to the host and does not fetch `access` itself. Left open: whether the client asks the room for the access object or the host supplies it. Not built in this lane.

## 3. Region lock indicator and shading in the core (PRM-026 criteria 1, 3, 4) — not taken

The engine has no lock indicator, no access-driven region shading and no live update of them (`packages/engine` has no `regionLabels`; the shell's labels come from a fake core in tests). Building it is a product change in `packages/engine` and `packages/element` with its own design choices (the icon and the label wording). Not built in this lane; criteria stay unticked.

## 4. Two-tab scenario (PRM-019 criterion 1, PRM-024 criterion 5) — not taken

Needs the document service room and two browser contexts against the same document, which the shell e2e harness (`packages/ui/e2e/harness`, a fake core) does not provide. Listed in the lane report under needsFromOthers.

## 5. Two owners changing grants on PostgreSQL (PRM-019 criterion 5)

Run on PostgreSQL in Podman in addition to memory: `services/document-service/test/control-plane/prm-019.grants-two-owners-pg.test.ts`. The harness creates and drops its own database; no shared object was touched.
