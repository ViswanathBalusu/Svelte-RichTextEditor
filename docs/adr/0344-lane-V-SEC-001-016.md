## Open questions and the default taken

1. **A burst of copies of one commit identifier (SEC-015, criterion 2, PostgreSQL).** Run on 2026-11-13 with `pnpm vitest run tests/security/test/replay-and-key-reuse.test.ts` (PostgreSQL in Podman, shared `docedit-test-postgres`): nine of ten cases pass, and the burst case fails at its first assertion (no `sync.ack` among the answers to 1000 copies; the test's `acks.length > 0`). The memory run is the same case in the story Notes. The criterion asks that every copy gets the same acknowledgement. The spec's own position is different: 04 §8 gives `rate_limited` with action `retry` for a refused resubmission, and SEC-018 and BE-030 bound the messages per connection, and a refusal in a row closes the connection with 4429 (session.ts, `#admit`, after 50 refusals). A plausible cause on PostgreSQL, not verified: the first commit is still being written when the refusals reach 50, so the socket closes before any ack is sent. Default taken: the spec's limits stand, criterion 2 stays unticked, and the test keeps checking what holds. Question for the owner: may an in-flight duplicate of a commit be acknowledged without spending the connection's message budget (a change to 04 G4 and to SEC-018), or is the criterion to be read as "one stored commit" only?
2. **`revoked` in `ch.open` (SEC-014, criterion 2).** Same question as lane U-SEC-001-016, docs/adr/0344-lane-U-SEC-001-016.md, question 1. Not changed in this round.
3. **Threads, comments, imports and workflow participant routes (SEC-016, criteria 1, 2 and 4).** These routes are in the OpenAPI definition (spec/dep/dep-1.openapi.json) but not served. A probe that gets 404 shows nothing about cross-document access, so criteria 1 and 2 are not ticked by a 404. Default taken: unticked until the routes exist. Criterion 4 is the open question on `forbidden` and `not_found` in the story itself.
4. **Browser scan of `de-*` details with comments and fills (SEC-009, criterion 4).** The element has no comment UI and the demo has no export port, so a scripted session that comments and exports cannot be run in this tree. Default taken: unticked. Typing is already scanned in packages/element/e2e/element.spec.ts (the `docText` check).
5. **SEC-006 criterion 4 (SVG upload and display).** Not run in this round: the asset upload path is not in the demo page.
