# ADR 0358: Lane V-HIS-017-032 proposals

Status: proposed (2026-11-13). Owner decisions are not made here.

## 1. A `legalHold` member on the document resource (HIS-031 criterion 4)

`GET /v1/documents/{id}` answers `legalHold: boolean`, true while at least one hold is placed on
the document. The spec gives the document resource no such member, so the name is a proposal. The
boolean never carries the reasons. The document ETag is not changed by a hold. The main session
should decide whether the member belongs in the document schema of `spec/dep/dep-1.openapi.json`.

## 2. The cold-segment mover needs a package dependency (HIS-029 criterion 1)

The move rules are in `@docedit/history` (`packages/history/src/cold-segments.ts`). The document
service cannot import them until `services/document-service/package.json` declares
`"@docedit/history": "workspace:*"`. That edit is outside this lane. Proposed with it: migration
for a segment index table, and a retention role (`docedit_retention`) that holds `delete` on
`doc_commit_payloads`, because `docedit_app` has only `select` and `insert` there (migrations
0002 and 0003). The scheduler task that calls the mover is the service's (BE-052).

## Open for the owner

- HIS-031 criterion 4 reads "set or released". This lane tests the set half only and leaves the
  criterion unticked. Whether the set half alone is enough is the owner's reading.

## 3. Whole-document restore route (HIS-019 criterion 1)

`POST /v1/documents/{id}/restore` with `{ toSeq }` (operation `restore`, `spec/dep`) is served in
`services/document-service/src/control-plane/restore-route.ts`. The response `{ seq, toSeq,
preRestoreSeq }` is a proposal: the schema names `RestoreResult` as a placeholder (gap G69). The
route refuses `region` (HIS-018) and `dryRun` (HIS-021) with `not_found` and a reason, because the
region steps and the comparison are in `@docedit/history`, which the service does not depend on
(section 2 above). The snapshot's reason `restore` is passed through `replaceContent`'s new
`reason` option (`src/data-plane/index.ts`, `src/seams.ts`); the stored origin of the commit is
`restore`. Decision for the owner: whether a restore to a seq that the caller's gate hides is
`forbidden` (as built, a seq below the gate) or `not_found` (the way a thinned seq is answered).
