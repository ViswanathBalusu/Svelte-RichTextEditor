Status: proposed (2026-11-13, lane U-FE-097-112, round 4). Decisions made while closing the browser
and container gaps of FE-097 to FE-112. None changes the spec; each is a reading or a test choice.
Lane V-FE-097-112 wrote `0306-lane-V-FE-097-112.md`; this file does not replace it.

## 2. FE-097 criterion 5 reading

The criterion says the start and end commands stay in the body, with a reference to FE-032. FE-032
criterion 4 is ticked on the web view's editing surface, and this lane reran its test
(`packages/element/e2e/s1-shadow-root.spec.ts`, `-g "never leave the body"`, 3 passed in Chromium,
Firefox and WebKit, 2026-11-13). Reading taken: the page view's caret is the subject of FE-097, so
the web view run is not counted as its evidence. The criterion stays open until the page view exists.

## 3. FE-104 criterion 5, states beyond the default shell

`packages/element/e2e/fe-104-target-size-states.spec.ts` measures the pointer controls of the
element's shadow root in three states: the command search, the language dialog opened through it,
and the context menu opened with Shift+F10. All controls measured are at least 24 by 24 CSS pixels
in Chromium, Firefox and WebKit (4 passed). The same inline-target exception as the default-shell
test is used (footnote references in the document's text are left out; WCAG 2.2 criterion 2.5.8).
The criterion stays unticked: the side panes are not measured, and the handles of criteria 1 to 4
do not exist. Reading taken: a criterion that names handles is not met by measuring only the
controls that exist; the owner or the accessibility specialist confirms this.

## 4. Test environment

No container was started by this lane. The browser runs used the element's Playwright config with
`DOCEDIT_DEMO_PORT=56061`, which the config serves itself, and `--output` in the scratchpad folder,
as ADR 0306 (V) section 5 describes. No shared PostgreSQL or object storage was needed, because none
of the stories closed here reaches a backend.
