# ADR 0230: Lane EXP-118 to EXP-123 open decisions

**Status:** proposed (2026-11-13). Written by the developer of lane EXP-118-123. The owner decides; until then the spec default below stands.

## Context

Lane EXP-118-123 covers the DOCX patching and round-trip stories (EXP-118, EXP-119, EXP-120), the LaTeX citations and bibliography (EXP-121), the DOCX citations (EXP-122) and export as the requester (EXP-123). Three open questions came up while working on them.

## 1. A `.bib` file or converter-written bibliography (EXP-121 criteria 1, 3 and 4)

- **Spec:** 09 §3 and §4 ask for a `.bib` file generated through typed emitters, and for biber to run in the sandboxed worker under the rules of 09 §9.3.
- **Default in use:** the converter writes the citation texts and the bibliography itself, in the two house styles (`numeric`, `authorYear`), through the `text` emitter. This is the default of owner decision 10 (`docs/owner-decisions-pending.md`), taken from the second review (SR-M20). Code: `packages/export-latex/src/citations.ts`.
- **Effect:** no `.bib` file is written, biber never runs, and the `tex` bundle carries the references as typeset text. EXP-121 criteria 1 (`.bib` and biblatex commands), 3 (biber in the sandbox) and 4 (`.bib` in the `tex` bundle) stay open.
- **Owner question:** keep the converter-written bibliography (no biber, one fewer program in the sandbox, citation styles limited to the two house styles), or add a `bibField` emitter with fuzzing and run biber under the sandbox rules.

## 2. Full export of a restricted view (EXP-123 criterion 1)

- **Spec:** 09 §2 and §9 say an export is built from the requester's projection.
- **Current state:** the job records the projection (`hiddenRegions`, `hiddenValues`, `view`), and a full export needs `manage` plus `options.full: true`. The worker refuses any job whose projection hides something (`services/export-worker/src/job.ts`, `unsupported_feature`, "not available yet"), so no bundle is built from a projection yet.
- **Default in use:** refuse rather than export in full. This is the safe default; it is the same answer for every target, so a DOCX of a restricted view is neither patched nor written (EXP-123 criterion 3 holds through the refusal).
- **Owner question:** none beyond scheduling the projection build in the worker.

## 3. Redacted form field values in the projected notice (EXP-123 criterion 2)

- **Spec:** each placeholder prints as a neutral notice.
- **Current state:** a hidden region prints the notice (`[This part of the document is not shown]`, or with its title when the projection shows it). A redacted form field value is listed in the manifest (`fieldValue`) and prints an empty field, not a notice.
- **Default in use:** no notice for a field value; the manifest is the record of what was hidden.
- **Owner question:** whether a redacted field should print the neutral notice too.

## 4. Word citation fields and the sources part (EXP-122 criterion 1, round 2)

- **Spec:** 09 §11 and §12, ADR 0017: citations become Word citation fields and the sources become the bibliography sources part, so that Word can update them.
- **Default in use:** a `CITATION` field per citation, tagged with the source identifier, `\l 1033` (en-US LCID), `\m <tag>` for each further source, `\n` for a suppressed author. The sources are one `b:Sources` custom XML item (`customXml/item<n>.xml`) whose datastore names `http://schemas.openxmlformats.org/officeDocument/2006/bibliography`. Source types map from CSL item types by a small table, others become `Misc` (`packages/export-docx/src/writer-citations.ts`).
- **Not verified:** Word itself is not run, so the switches, the source-type names and the order of the `b:Source` children are unconfirmed against Word. Narrative mode writes no switch; locators and affixes go only into the cached text.
- **Owner question:** whether the sources part should carry every defined source (as written) or only the cited ones, and whether the field switches need a Word check before the criterion is ticked.

## Consequences

Criteria left open for these reasons are noted in `docs/stories/EXP-export.md` under EXP-121, EXP-122 and EXP-123.
