# ADR 0351: lane V-PRM-052-067 interpretations

Status: proposed (2026-11-13). Owner decisions are not made here; this records the reading this lane used so the owner can confirm or reverse it.

## Context

Lane V-PRM-052-067 closed blocked criteria in PRM-052 to PRM-067 by writing tests against the real environment. Some criteria name a refusal code or an outcome that the product does not produce in exactly that form. Where the lane had to read a criterion, it wrote the reading here.

## Decisions proposed

1. PRM-057 criterion 5 (row 12): "refused" for a raw compile log requested without `edit` is met by withholding the log. The export route (`services/document-service/src/control-plane/export-routes.ts`) answers the read with the output URL and no log field. A user without `view` on the document is refused the export itself (401, 403 or 404). Proposed: keep this reading. If the owner wants a refusal code instead, the criterion's wording changes.

2. PRM-053 criterion 3 names `invalid_op` as well as `permission_denied`. Both raise `dep.commit.rejected.v1` through the same room path (`#auditRejection`, `services/document-service/src/data-plane/room-host.ts`). The test `tests/security/test/prm-053-webhook-events.test.ts` covers both codes. Proposed: no further change.

3. PRM-053 criteria 1 to 3 are proven with a recording `Transport` in place of the egress proxy. The egress proxy (BE-056) has its own tests. Proposed: a real HTTP delivery to a receiver is a separate criterion for BE-055 or BE-056, not for PRM-053.

## Consequences

- No product behaviour changed in this lane round.
- The throttle figures used by the test (window 60 s, maximum 5) are test values; ADR 0146 still owns the production figures.

## Not decided here

- Whether a grant change or a confidential-region request is refused with `permission_denied` or `forbidden` (PRM-066 criterion 2). The owner decides.
- The restore route and the workflow transitions (PRM-052 criteria 4 and 5, PRM-058 criterion 5). They are not built (FRW).
