# ADR 0308 (lane V-FE-129-141): decisions taken while closing blocked criteria

**Status:** proposed, 2026-11-13. Not decided by the owner. Each point below is the reading of the spec default, or the narrowest reading the story allows, and is open for review.

## Context

Lane V-FE-129-141 closed criteria that earlier rounds left open with a note such as "needs a browser run" or "needs a change in package X". Where a story or spec left a point open, the lane recorded it here and did not decide it silently.

## Decisions

1. **Browser zoom is simulated by the CSS viewport width (FE-138 criterion 2).** A 640 CSS pixel window is the layout a 1280 pixel window shows at 200 per cent, and 320 CSS pixels is the WCAG 1.4.10 reflow width. The Playwright harness does not drive the browser's own zoom control. The criterion is ticked on this proxy; a run with the real browser zoom remains open for a human check.

2. **Table style header row shading is resolved in the cascade (FE-131 criterion 1, partial).** `resolveTableFormat` returns `headerRowShading` from the table style chain. The CDM gives a table no shading of its own, so a direct override has nothing to set. Drawing the shading is the web view's and is not done here.

3. **A `pageCount` field prints in decimal (FE-137 criterion 4, proposed reading).** The spec does not say whether the total page count follows the section's page number format. The lane uses decimal for it. The `page` field follows the section's `pageNumberFormat`, and a missing `pageNumberStart` counts from 1 for the first section (the CDM default of `continue` is the caller's to resolve).

4. **A page field's text needs the typesetter's number (FE-137 criterion 4).** `fieldText` computes `page` and `pageCount` only when the caller gives the number. The layout that places page numbers is not built, so the criterion stays open.

5. **Paragraph format values are stored with the CDM's own ranges (FE-129 criterion 1, storage half).** `setParagraphFormat` (`packages/engine/src/paragraph-format.ts`) writes the paragraph properties of `paragraphProps` (`packages/model/src/definition/cdm1.ts`) with the CDM ranges (`LENGTH`, `ULENGTH`, line spacing 1 to 31680). `tabs` and borders and shading are left to criteria 2 and 5. The command is not yet registered in `core.ts` or `api.ts`, which are shared files; criterion 1 needs the web view to show the values, so it stays unticked either way.

6. **A list with a `role="list"` parent is not built (FE-130 criterion 6, FE-105 criterion 3, proposed).** The list view gives each numbered paragraph `role="listitem"` as a node decoration (`packages/engine/src/view/list-view.ts`). A decoration cannot wrap sibling paragraphs in a new element, and a node view for the body cannot wrap them either, because ProseMirror maps the children of a node view's content one to one. Giving the items a list parent needs a change to how the body is rendered, which the owner or the element lane should decide. Left open.

7. **FE-130 criterion 3 (labels match the PDF) is blocked by the missing PDF output.** No package in the repository writes a PDF. The layout (`packages/layout/src/flow.ts`) prints the labels that `computeLabels` gives, which is tested in `packages/layout/src/numbering-labels.test.ts`, but nothing compares them with a PDF. Left open until a PDF exporter exists.

8. **A new page setup goes after the last page setup in `defs` (FE-135 criterion 2, a fix, round 4).** `insertSectionBreak` appended the new `page_setup` at the end of `defs`, which the content expression `page_setup+ role_def* rule_def* source_def*` does not allow after a source, rule or role definition. The module now places it after the last page setup (`pageSetupInsertPos` in `packages/engine/src/breaks-sections.ts`), with the end of `defs` as the fallback. This is a repair to the module's own placement, not a choice of the owner. Tested in `packages/engine/test/fe-135-section-after-sources.test.ts`.

9. **A placeholder's whole-only selection is tested on the live view (FE-141 criterion 1, partial, round 4).** The check uses the editing schema's `hidden_region` with a text selection that crosses it. The page view that the criterion also names is not built, so the criterion stays open.

## Consequences

Nothing here changes a stored document. The changes are the model's cascade and field text (additive), and a browser test file in `packages/ui/e2e`.
