# ADR 0222: Open points found by lane EXP-014-026

**Status:** proposed. Written by the developer of lane EXP-014-026 (round 1, 2026-11-13). Not decided; the owner or the main session decides.

## Context

Stories EXP-017, EXP-018 and EXP-019 were checked against the converter output and the house class source. Two points the spec leaves open, or that differ from the story text, were found. The spec default is kept in the code. Neither point was decided silently.

## Point 1: unit of `exact` and `atLeast` line spacing (EXP-021 criterion 4)

The story says that, when `lineRule` is `exact` or `atLeast`, "the value is a length". The converter writes the model's value as an integer of twips (`\DElse{n}`, `\DElsa{n}`, `src/props.ts`). The class reads it as twips (`class/docedit.cls`, comment "exact and at least in twips (03 §2)"). The converter does not pass it through the `dimen` emitter (09 §4), unlike the other lengths. The output is correct for the class, but it is not the emitter route.

Default kept: twips integers as the class reads them. Open: whether the emitter route is required, which would change the class macros and the `\DElse` and `\DElsa` tests. Status of EXP-021 itself: not ticked by this lane, because another lane holds it ("In progress: lane export-latex-2").

## Point 2: `fancyhdr` for headers and footers (EXP-018 criterion 1)

The story says that `fancyhdr` page styles are generated per page setup. The house class builds its page styles itself (`\DE@pagestyle`, ADR 0032 §6) and does not load `fancyhdr`. 09 does not name `fancyhdr`.

Default kept: the class's own page styles, which already cover the first-page and even-page variants. Open: whether the story's `fancyhdr` wording stays. Criterion 1 is not ticked.

## Point 3: equation label targets (EXP-019 criterion 2)

The story names the equation label as a `ref` target. The `eq:` scheme of `referenceText` is not tested in this lane, because it needs a math node. Criterion 2 stays unticked until it is.
