# 0347 Lane V-SEC-049-064 (round 1): real-environment closure of SEC stories

**Status:** proposed. No decision is taken here; the entries below are findings and defaults.

## Context

Lane V-SEC-049-064 works the range SEC-049 to SEC-064 from the highest number down, closing the criteria that earlier lanes left open for want of PostgreSQL, object storage, a container, a browser or another package.

## Findings of this round

1. **SEC-049 closed on runs.** `tests/security/test/sec-049-backup-sealing.test.ts` (Node.js, 4 of 4 pass) and `services/document-service/test/data-plane/be-096-backup.pg.test.ts` (PostgreSQL and the S3-compatible store, 3 of 3 pass, run by this lane) cover criteria 1 to 4. The limit is recorded in the story: the backup key's storage and rotation are open in the spec, and the key comparison is by identifier, because the live keys' private material is not exposed.
2. **SEC-054 criterion 1 is still blocked.** `packages/element/e2e/sec-054-network-tour.spec.ts` fails in Chromium at `openEmbed`: `__embed` is never set. The document that the embed page builds validates on its own (`validate()` of `regionDocument()` and of `spikeDocument()` returns valid, run with Node.js), so the defect is in the page's runtime path or in the demo build. The demo build (`node demo/build.ts`) also failed in this lane's run, while other agents were editing the same tree; the build error was not isolated. Owner: the element demo. Not changed here.
3. **SEC-053 criterion 1 cannot close.** The LuaTeX 1.17 gate is a RUN line in `services/export-worker/Containerfile` (its regular expression is tested by `engine-config.test.ts`), but the image is the full TeX Live scheme, not the curated installation of EXP-073, so the criterion's first half is not met.
4. **SEC-057 criteria 1, 3 and 6 need a document purge and the backup ageing rule**, which `services/document-service` does not have (`asset-sweep.ts` and `backup.ts` are not a purge of a document). Not built here.
5. **SEC-064, SEC-056, SEC-060** were not extended in this round. Their open criteria need new canary surfaces (assets, exports, comments, presence), a PostgreSQL erasure scenario, and row and code tagging, each of which is larger than the time left in this round.

## Defaults taken

- Nothing new is decided. The backup key's storage, its rotation and the retention period stay as the spec leaves them (06 §13).
