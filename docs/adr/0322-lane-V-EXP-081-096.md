# ADR 0322: Blocked export criteria in the DOCX writer (lane V-EXP-081-096)

Status: proposed

Date: 2026-11-13

## Context

Lane V-EXP-081-096 closes the criteria of EXP-081 to EXP-096 that earlier lanes left blocked on the
environment (Word, PostgreSQL, a container, a browser). This round it works from EXP-096 down. Open
questions found on the way are recorded here, not decided.

## Decisions taken in this round (proposed)

1. EXP-090 criterion 7 (schema validity) is tested with the Open XML SDK validator
   (`packages/export-docx/tools/ooxml-validate`, DocumentFormat.OpenXml 3.5.1, Office 2019 schema
   set) over every writer projection and every corpus projection. The first run found a defect:
   the cell and paragraph shading (`w:shd`) lacked the required `w:val`. The `shd` lens in
   `packages/export-docx/src/props.ts` now writes `w:val="clear"` and `w:color="auto"` with the fill.
2. EXP-090 criterion 2 (formatting Word resolves equals the cascade of 03 §6) is tested by reading
   the effective character formatting from Word COM
   (`packages/export-docx/tools/word-cascade/read-word-formatting.ps1`) and comparing it per character
   with `resolveParagraph` and `resolveRun`. Hidden runs (`w:vanish`) are skipped, because Word's
   character collection leaves them out in the reader's view. The writer's own tests check the mark.
   Reading: "the formatting Word resolves" is taken as Word's effective character properties; the
   paragraph properties (spacing, indents, tabs) are not compared in this round.

## Open questions (not decided here)

a. EXP-090 criterion 1 says the file opens in Word and LibreOffice. Word opened 85 of 86 files
   without a prompt (`scripts/word-open-check.ps1`, Word 16.0 build 16.0.20527); the one refusal is
   a deliberately damaged file. LibreOffice is not installed on the reference machine, so the
   criterion stays open until it is.
b. EXP-090 criterion 7 says "when CI validates". The validator runs in the test; the CI job that runs
   it is root configuration (`.github/`), which this lane may not edit. Owner or main session.
c. EXP-090 criterion 6 needs the shared fixtures of EXP-115, which belong to another range.
d. EXP-090 criterion 1 has no DOCX target in the export worker: `services/export-worker` takes `pdf`
   and `cdm` only, and wiring `export-docx` in needs `@docedit/export-docx` in
   `services/export-worker/package.json`, which this lane may not change.
e. EXP-096 (equations in DOCX) waits on EXP-054, the converter spike, which has no decision. A
   converter must be chosen and installed, and a GPL converter runs as a separate process. The
   download is not made in this round (it needs the user's permission).
f. EXP-093 criterion 4 (comments anchored to a range) and criterion 2 (suggestion dates from the commit
   time) need the export input shape of ADR 0228 and the job host (EXP-098). Not decided here.
g. EXP-095 criterion 6: the writer writes the `grants` part exactly as the host gives it, and a
   restricted requester's view of grants and of role and rule definitions is undecided (ADR 0144).
h. EXP-091 criterion 2: the CDM `image` node has no `align` attribute (`packages/model/src/definition/cdm1.ts`),
   so inline pictures cannot meet it without a model change. Owner or spec.

Round 5 (lane V-EXP-081-096, 2026-11-13), stories EXP-085 and EXP-083:

i. EXP-085 `tex` target, output file and media type: the spec does not name them. Spec default
   used: the worker writes the bundle archive (`texArchive`) as `source.tar`, media type
   `application/x-tar`, with no compile (`services/export-worker/src/job.ts`, `TEX_OUTPUT_FILE`).
   Proposed; the owner may rename it.
j. EXP-085 criterion 4 (licence manifest in the archive) is open: `scripts/licence-manifest.ts`,
   which the story names, is not in the repository, so the worker has no manifest to read. Needs
   EXP-073 or an owner decision on where the manifest file lives.
k. EXP-083 criterion 4 (non-colour cue) is ticked on the source-level underline (`\DEul`) and
   strike-through (`\DEst`). Whether a reader needs a cue that the PDF draws is not settled here.
l. EXP-083 criterion 3 (rows, tables and atoms marked as inserted or deleted) is open; the markup
   of blocks is a converter change, not decided here.

Round 4 (lane V-EXP-081-096, 2026-11-13), range check. Stories EXP-081 to EXP-096 not on the
do-not-redo list: EXP-081 and EXP-084 only (EXP-082 and EXP-086 are fully ticked). Nothing ticked
this round. Reasons, from reading the code and the spec:

m. EXP-081 criterion 3 (a whole-block `del` is honoured under `accept` only if it passes the
   permission rules). Spec 09 §10 says "passes the permission rules" and does not say which rule
   the exporter applies. The candidate is P4 (`packages/authority/src/permissions/suggestions.ts`),
   which needs the identity owners of each suggestion identifier, held by the document service and
   not passed to the converter. Needs a payload decision (ADR 0228 input shape). Not decided here.
n. EXP-081 criterion 4 (a mark the exporter cannot verify never drops a region; a diagnostic names
   the block). "Cannot verify" is not defined in the spec or in ADR 0032. The converter reads only
   `ins` and `del`. Open question; spec default not applied because no default exists.
o. EXP-081 criterion 2 (`reject` reverts `fmt` to `before`) conflicts with ADR 0032 §1 (`fmt` shown
   as suggested in both modes). Recorded in docs/adr/0142-export-latex-4-backlog-batch.md. Owner.
p. EXP-084 (margin comments) has no margin writer and no comments input. The export payload has no
   comment threads, and `services/export-worker/src/profile.ts` refuses `comments: margin`. Needs:
   the service's mapped ranges at `seq` in the payload (ADR 0228), a margin macro in the house class
   (or a core `\marginpar` with a class-version decision, EXP-078), the detached-thread warning, and a
   LuaLaTeX run in the sandbox. Author names: the service holds only surrogates (08 §13); open.
   Too large for one lane round; left open.
