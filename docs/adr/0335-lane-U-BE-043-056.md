# ADR 0335: Lane U-BE-043-056 decisions (proposed)

Status: proposed. Owner decisions stay the owner's; the spec default is used where it exists.

## Context

Lane U-BE-043-056 (round 2) closes criteria that earlier lanes left open for want of PostgreSQL,
object storage, a container or a browser. Decisions the spec leaves open are recorded here.

## Decisions

1. **Search tables outside the migrations (BE-054).** `search_entries` and `search_tokens` are
   defined by `SEARCH_INDEX_DDL` in `services/document-service/src/control-plane/search-index-pg.ts`,
   as the webhook delivery table is. Adding a migration changes the schema version every database
   expects, which the main session sequences. Default: not in a migration until it is sequenced.

2. **Token length (BE-054).** A token longer than the PostgreSQL btree row limit (about 2,700
   bytes) makes the insert fail, and the indexing job fails with it. The spec does not say how an
   overlong token is handled. Default chosen here: no truncation, so the failure is visible and the
   index never holds a token it did not index. Alternative for the owner: skip tokens above a stated
   length and count them.

3. **Ordering of hits (BE-054).** Document identifiers are compared in the `C` collation, so the
   PostgreSQL and in-memory indexes give the same order for any identifier. The spec does not state
   an order beyond ranking; this follows the in-memory index.

4. **Sequence guard (BE-054).** A lower sequence never replaces a held one. It is checked in the
   same statement that writes the entry (`ON CONFLICT ... WHERE`), so two racing indexers keep the
   higher sequence.

5. **Retention of abandoned uploads (BE-046, round 3).** The spec gives no retention period for
   orphan assets or abandoned uploads (Open questions of the backlog). Default chosen here: a
   quarantined upload that nobody completed is removed once its upload window has ended, that is
   the `upload_expires_at` its row carries from creation. The period is therefore the window of the
   signed upload. A row a worker has taken is never removed by this job. The owner may set a longer
   period for the orphan and abandoned cases; that is an owner decision.

6. **Orphan retention and the `doc_assets` table (BE-046, round 4).** Migration `0064_doc_assets.sql`
   creates `doc_assets` (BE-044). A ready asset with no attachment row, settled before
   `now - orphanRetentionMs`, is removed with its row and its object. The spec gives no period, so
   no default is set: the composition leaves `orphanRetentionMs` unset and orphans are kept. Reason:
   until the persist path writes `doc_assets` rows (BE-044), a referenced asset looks unattached, and
   removing it would break a document. The owner chooses the period; the code takes any value. The
   shared object is deleted only when no other row names its key.

7. **Preview window on PostgreSQL (BE-051, round 4).** The window is measured with the database's
   job times and the service's clock. The new PostgreSQL test runs on the real clock and does not
   move it; the moved-clock block of `export-jobs.test.ts` is outside this lane and stays red there.

## Consequences

- BE-046 criterion 1 is ticked on the sweep with an explicit retention. Criterion 2 needs the BE-044
  persist write for earlier versions. BE-044 criterion 1, 2, 3 and 5 need the persist path (BE-024),
  which this lane did not change.
- Criteria 1 and 3 of BE-054 stay unticked until the migration, the post-checkpoint queueing and the
  purge pipeline exist. See the story's Notes.
- Nothing here changes root configuration, `package.json`, CI or any other lane's package.

## Round 5 (BE-046 criterion 4, BE-054 criterion 2)

Status: proposed. Two defaults were taken where the spec is silent; the owner may change them.

- Legal holds and the asset sweep (BE-046 criterion 4): an asset whose document has a stored hold is kept by both sweeps. Holds have no release today, so every stored hold is in force. A held upload stays in its batch, so more held uploads than the batch (500 in the deployed task) delay the other rows of that tenant.
