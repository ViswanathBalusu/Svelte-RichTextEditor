# ADR 0218: Lane PRO-099-112, round 2 decisions

Status: proposed. Owner decisions are the owner's; the defaults below are the spec defaults.

## Context

Lane PRO-099-112 took the stories of its range that still had unticked criteria. Stories PRO-099
to PRO-108, PRO-110, PRO-111 and PRO-112 were handled in earlier rounds. PRO-112 is fully ticked.
Only PRO-109 (test-mode switch) had open criteria in this round.

## Decisions

1. **PRO-109 criterion 4 ticked.** The discovery document at `/.well-known/dep` names no switch and
   no `/_test/` path, and has the same top-level keys with the switch on and off. Evidence:
   `services/document-service/test/control-plane/pro-109-discovery.test.ts`.

2. **PRO-109 criterion 1 left open.** Tick needs a check that every timer has its specified value
   with the switch off. That check is not written.

3. **PRO-109 criterion 2 left open.** The token lifetime (60 s) is covered by
   `be-079-token-lifetime.test.ts`. The shorter lease expiry and idle timeouts are not tested.

4. **PRO-109 criterion 3: open question for the owner.** The criterion says a token expiry, a lease
   lapse and an idle close each happen "within seconds". `TEST_TIMERS.tokenLifetimeS` is 60 s,
   which is a minute. The lease (3 s) and idle room (1 s) and hello timeout (2 s) fit "seconds".
   Options: (a) read "within seconds" as covering a 60 s token lifetime and tick; (b) set the test
   token lifetime to a few seconds, which the 15 minute maximum allows; (c) leave open. Default
   taken here: (c), because the value is an owner-visible setting and the criterion is not met as
   written.

5. **Timer values differ between two places.** `server.ts` passes `TEST_TIMERS` (room idle 1 s,
   hello 2 s, lease 3 s). The data plane's `testDefaults` in `data-plane/index.ts` uses room idle
   2 s and hello 2 s, but the server's explicit values win. Not changed; noted for the owner of
   the data plane.

## Consequences

PRO-109 stays open for criteria 1 to 3.

## Round 3 (2026-11-13)

6. **PRO-109 criterion 1 partly checked.** `pro-109-timers.test.ts` checks the timers that 05 and 06
   give a value to, with the switch off. Open: the job lease, node lease and outbox poll have no
   specified value; the owner or the spec must give one before the criterion can be ticked.

7. **PRO-109 criterion 2 open: region lease expiry.** The service has no region lease route, so no
   lease lifecycle runs in `services/document-service`. Owner decision needed on when the leases
   feature is built; not decided here.

No root configuration, package file or shared file other
than the story and this ADR was changed.
