# 0217. Lane PRO-085-098: decisions and open points

**Status:** proposed (2026-11-13). Written by the developer of lane PRO-085-098 in the backlog batch, round 1. Not reviewed by the owner.

## Context

Lane PRO-085-098 covers stories PRO-085 to PRO-098 of `docs/stories/PRO-protocol.md`. This round ticked one criterion with a test (PRO-097 criterion 3). The other open criteria in the range stay unticked, each with its reason in the story's Notes. This note lists the decisions the lane took and the points that need an owner or a spec decision.

## Decisions taken (proposed)

1. **Lease heartbeat cadence (PRO-097 criterion 3).** 07 §10 gives the lease expiry (five minutes by default) and the eight-hour maximum total length, but no interval between heartbeats. Default taken: the next heartbeat is armed at half of the time left before the lease expires, using the expiry of the latest response. Heartbeats stop when the server refuses one, when the lease has no entity tag, when it has expired on the local clock, or when it has reached eight hours from acquisition. Release stops them before the DELETE and restores them if the DELETE is refused. The timer is `armHeartbeat` in `packages/backend-dep/src/review.ts`, and the backend passes its own timers through the new optional `clock` of `ReviewPortsHost`. Without a clock, only explicit `heartbeat` calls extend a lease.

## Open points that need a decision

2. **PRO-096 criterion 2 (exports progress).** `ExportsPort` in `packages/protocol/src/ports/optional.ts` has `request`, `get` and `cancel` and no progress stream. Polling until a terminal state needs either a new port member (for example a watch call) or a rule that `request` resolves only at a terminal state. Both change a port typing owned by `packages/protocol`. Default: criterion stays unticked.

3. **PRO-085 criterion 5 (toolbar `none`).** The built-in commands in `packages/ui/src/commands/builtin.ts` have ids such as `edit.undo` and run closures. `exec` in the element takes the engine's `CommandName` (`packages/engine/src/api.ts`: `bold`, `undo`, and so on), which is a narrower set. Whether `exec` should accept registry ids, or the host should reach each command another way, is not stated in 05 §8.1 or 13 §4. Default: criterion stays unticked.

4. **PRO-090 criterion 4 (`destroy()` calls `backend.close()` once).** Checking this at element level needs a DOM and the browser suite. Default: stays unticked.

5. **PRO-095 criteria 1 and 2 (`catchUp: "page"`, `sync.caughtUp` ordering).** Carried over from ADR 0110, question 1. No test server answers `page`. Default: stays unticked.

6. **PRO-098 criterion 2 and PRO-099 criterion 1.** These need `backend-local` (PRO-100) and the element's rendering. Default: stays unticked.
