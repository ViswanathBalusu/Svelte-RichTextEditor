# 0213. Lane PRO-029-042: open questions raised by the protocol stories

Status: proposed (2026-11-13). Owner decisions are the owner's; this record only states the question and the spec default.

## Context

Lane PRO-029-042 (round 2) ticked the criteria it could test and left the rest open. Three questions in its stories are not answered by the spec and were not decided in the code.

## Question 1: strip unknown members of `access` (PRO-032 criterion 5)

The criterion says that an `access` object with an unknown field is read and "the field is ignored (PRO-005)". PRO-005 says to ignore unknown members when reading. The protocol client (`packages/protocol/src/client/channel.ts`) does not reject such an object and reads the known members, but it passes the object to the host with the unknown member still present.

- Spec default: keep the object as received and let typed hosts read only the members they know (PRO-005 reading rule). This is what the code does now.
- Alternative: strip unknown members before the `access` effect is emitted, so no host can depend on them.

Decision needed from the owner. The criterion stays unticked until one is chosen.

## Question 2: `rate_limited` on REST (PRO-039 criterion 4)

The criterion says the client waits for `retryAfterMs` or `Retry-After`. On the socket, `backend-dep` waits. On REST, `packages/backend-dep/src/rest.ts` returns the error with `retryAfterMs` and does not wait.

- Spec default: the REST layer surfaces the hint and the caller decides when to resubmit. This is what the code does now.
- Alternative: the REST layer waits once for `retryAfterMs` before it returns the error.

Decision needed from the owner.

## Question 3: `de-auth-required` and the port event (PRO-039 criterion 1)

`backend-dep` raises the port event `onAuthRequired`, and the element is expected to turn it into the DOM event `de-auth-required`. The story names the DOM event under `backend-dep`.

- Spec default: the port event is the backend's part; the DOM name is the element's (PRO-086). No change.
