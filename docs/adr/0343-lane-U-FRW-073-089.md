# ADR 0343: Lane U-FRW-073-089, round 2

**Status:** proposed (2026-11-13). Lane U-FRW-073-089, round 2. Owner decisions are listed here with the spec's default and are not decided by this lane.

## Context

Round 2 of the lane took the stories of FRW-073 to FRW-089 that earlier rounds left partly open. FRW-073, FRW-076, FRW-077, FRW-078, FRW-079 and FRW-080 were handled in earlier rounds and were not reworked, except where noted below. This round covers FRW-074 (criterion 3, browser), FRW-083, FRW-084, FRW-085, FRW-086, FRW-087 and FRW-089 (decisions and remaining criteria).

## Work done and what it proves

1. **FRW-074 criterion 3 (role markers, non-text contrast and forced colours).** `packages/ui/e2e/frw-074-markers.spec.ts` measures, in the page, the WCAG ratio of each role marker (`.de-role-icon`) against the nearest opaque background above it, in the light, dark and high-contrast themes, and checks that the icon opts out of forced colours and paints `CanvasText` under forced colours.
   - Run: `DOCEDIT_UI_PORT=56432 pnpm exec playwright test -c packages/ui/playwright.config.ts packages/ui/e2e/frw-074-markers.spec.ts`. Result: 10 passed, 2 skipped (the forced-colours test is Chromium only; Playwright emulates it there).
   - Light and high-contrast pass the 3:1 check in all three browsers.
   - **Dark theme fails.** The author colour `rgb(13, 71, 161)` (`#0d47a1`) paints on `rgb(32, 36, 42)`, a ratio of 1.81:1 (measured in Chromium). The test records this as `test.fail` so that the suite stays green while the defect is open. When the rule below is decided, remove the `test.fail` line.
   - Criterion 3 stays unticked.

2. **FRW-080 criterion 5 (PDF page starts with an empty and a filled field).** `services/export-worker/src/frw-080-page-starts.e2e.test.ts` compiles the same 90-paragraph document in the sandbox three times: the field empty, with a short value and with a value longer than its box. It compares the block-level page starts (`layout.pages[].starts`) and the block pages (`layout.blocks[].page`) that the class writes.
   - Run from the repository root: `pnpm vitest run --project node services/export-worker/src/frw-080-page-starts.e2e.test.ts`. Result: 1 passed (Podman with the `cgroupfs` machine route, worker image `localhost/docedit-export-worker:s4`).
   - This is the evidence for FRW-080 criterion 5. FRW-080 was handled in an earlier round, so its story file is not edited here. The main session can tick the criterion with this file as evidence.
   - The comparison reads the class's layout, not the text of the PDF.
   - Readiness note: `sandbox-ready.ts` runs Podman commands with a 30 second timeout. On a loaded machine the test skipped twice with "podman info failed" and "image not built", although both succeeded when run alone (3 to 15 seconds each). The test is not wrong when it skips; the readiness timeouts are the owner's to review.

3. **FRW-074, FRW-083, FRW-089 story notes.** Pointers to this ADR were added to the Notes of these stories. No criterion was ticked in them.
