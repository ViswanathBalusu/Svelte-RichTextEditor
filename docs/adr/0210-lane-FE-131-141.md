# ADR 0210: Lane FE-131-141, round 3 decisions

Status: proposed (2026-11-13). Not decided by the owner.

## Context

Lane FE-131-141 (engine lane, round 3) ticked criteria that the story text leaves open to reading. The choices below were made by the lane, not by the spec, and are listed here so that the owner or the next review can confirm or reverse them.

## Decisions

1. FE-132 criterion 1 ("insert a picture file from my device") is ticked on the engine path only. `pasteImage` in `packages/engine/src/image-paste.ts` hands a picture file to the assets port, which quarantines and validates it, and the document keeps the asset identifier and sizes. The file chooser that starts this path is UX's and is not built. Spec default used: the engine's upload path is the insertion path.
2. FE-132 criterion 4 (caption holds a `seq` field) is ticked on the core command `insertCaption` (figure captions only). Table and equation captions remain open under FE-134 criterion 1.
3. FE-135 criterion 2 is ticked for the four start types of `SECTION_STARTS` (`nextPage`, `continuous`, `evenPage`, `oddPage`), checked by `packages/engine/test/fe-135-section-starts.test.ts`. The new test checks that each section break is a child of `body` with its own page setup.
4. FE-134 criterion 5 (`cached` holds the last computed text) is ticked on the field's `cached` text written by `insertCaption` and `insertReference`, and on `refreshCaches`. Whether the editor refreshes `cached` after every change (criterion 3) stays open: it is a sync decision.

## Round 4 decisions (2026-11-13)

5. FE-141 criterion 3 (copy, cut, drag): a copy or cut of a selection that holds a `hidden_region` placeholder or a redacted value is refused as a whole, with the reason `placeholder` or `redacted`, and writes nothing. The cut then deletes nothing. The spec says "neither is copied" and does not say whether the rest of the selection is copied. Spec default used: refuse the whole copy, which is the literal reading and copies nothing the reader did not ask for. Implemented by `copyRefusal` in `packages/engine/src/clipboard.ts`, called from `copySelection` in `packages/engine/src/core.ts`. Criterion 3 stays unticked because a drag is the view's.
6. FE-139 criterion 4 (find skips preserved content and reports how many atoms it skipped): the reported count is the number of preserved atoms in the body whose fallback text contains the query (case-sensitive, as `findMatches` compares). The spec does not define "skipped". This is a proposed reading. `skippedPreservedAtoms` in `packages/engine/src/preserved-find.ts` gives the count; the core's find state does not yet report it, so the criterion stays unticked.
7. FE-137 criterion 5 is tested for its storing half only: a watermark of 1 to 255 characters is stored on the page setup and cleared with `null`. The 255-character limit is the engine's own (`page-setup-commands.ts`), not a figure the spec gives. The spec states no limit, so this is a proposed reading for the owner to confirm or change.

## Consequences

Ticks above depend on the modules named in each story's Evidence line. If the owner reads "from my device" as a file-chooser test, FE-132 criterion 1 must be reopened.

Round 4 adds no new tick. Its rules (5 to 7) change what the engine refuses and reports, so the owner should confirm 5 and 6 before any criterion that depends on them is ticked.
