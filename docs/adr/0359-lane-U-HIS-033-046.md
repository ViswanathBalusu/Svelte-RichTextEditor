# ADR 0359: Lane U-HIS-033-046, environment-backed closure of history stories

**Status:** proposed (2026-11-13). Lane U-HIS-033-046, round 1.

## Context

Stories HIS-033 to HIS-046 (`docs/stories/HIS-history.md`) carried criteria left open because they needed PostgreSQL, object storage, a browser, a container, another package or an owner decision. This lane ran the test environment (Versity S3 Gateway in Podman, `docedit-test-s3`) and checked which open criteria it could close.

## Decision (proposed)

1. **Write-once storage (HIS-036 criterion 4) uses S3 Object Lock in COMPLIANCE mode.** `S3ObjectStore.putRetained` writes an object with a retention date, and `createBucket({ objectLock: true })` creates the bucket. Probed on the test gateway on 2026-11-13: a delete and an overwrite of a retained object by the root credentials return HTTP 403 (`AccessDenied`, "protected by object lock") until the retention date, and succeed after it. COMPLIANCE is the spec default for "cannot be altered or deleted ... even by the operator's own credentials"; GOVERNANCE would let an operator with bypass rights remove the entry, so it is not used. The owner confirms the mode.
2. **The production bucket for anchors must be created with Object Lock enabled.** This is an operator task and is not checked by any test here.

## Consequences

- No product behaviour changed outside the new `putRetained`, `createBucket` and `deleteBucket` methods of `S3ObjectStore`.
- The test creates and removes its own bucket and object. Two probe buckets created while the probe was written were removed on 2026-11-13.

## Round 2 (2026-11-13)

Survey of HIS-033 to HIS-046, excluding the stories that earlier rounds handled (HIS-034, 035, 036, 037, 038, 039, 040, 042, 045, 046):

- HIS-033: every criterion is ticked. Nothing to close.
- HIS-041 (delete a document's history by destroying its key, phase 4, could): untouched. It needs per-document keys, sealing of commits, checkpoints and cold segments with them, and a key destruction operation. None exists (see the Notes of HIS-041, which this round extends). Its prerequisites SEC-029, SEC-032, SEC-056 and SEC-057 are unticked. Not started; it is a build, not a test-environment gap.
- HIS-043: every criterion is ticked. Nothing to close.
- HIS-044: criteria 1 and 2 are ticked. Criterion 3 needs the owner or operations to set the limit that applies to the map. The spec does not give one and the measurements are from one seed and one machine, so no limit is written here. Owner decision.

No criterion was ticked in round 2. No product code or test changed in this round. The only edit is the Notes line of HIS-041 in `docs/stories/HIS-history.md`.
