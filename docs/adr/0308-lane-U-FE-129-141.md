# 0308. Lane U-FE-129-141: decisions taken while closing blocked criteria

Status: proposed (2026-11-13, lane U-FE-129-141, round 1)

## Context

Lane U-FE-129-141 closes the criteria that earlier lanes left open with a note. Where the spec
leaves a reading open, the lane takes the default below and records it here, so the owner can
confirm or change it.

## Decisions

1. **Variant stories are created by the page setup command.** `setPageSetup` builds the
   transaction with `turnOnVariants` when a `differentFirstPage` or `differentOddEven` flag is set
   to true and the caller gives a `storyIdOf`. The core passes its identifier source. A story
   identifier already in use refuses the command with `story-conflict` and changes nothing.
   The spec does not say whether turning a flag off removes its stories; this lane keeps them.

2. **A refused story identifier is a refusal, not a retry.** The core does not pick another
   identifier when the one it generated is taken.

3. **A link to a web page opens in a new browsing context.** `MARK_RENDERING.link` in
   `packages/engine/src/schema.ts` sets `target="_blank"` on an allowed external link (FE-067 and
   FE-133 criterion 4 state the rule; the value is the spec's). An in-document `#` link keeps the
   current context, because a new context would not show the target. Tested in
   `packages/engine/src/fe-133-link-open.universal.test.ts`.

4. **Zoom by keyboard means Tab and Enter on the status bar's zoom buttons (FE-138 criterion 4).**
   The criterion asks that the three zoom commands be reachable without a pointer. The status bar
   buttons are reached with Ctrl+F6 and Tab and activated with Enter; no shortcut key is bound.
   Tested in `packages/ui/e2e/fe-138-zoom.spec.ts` (Chromium, Firefox, WebKit).

5. **A footnote's number comes from its place in the body (FE-135 criterion 4).** The number the
   reader sees is the count of footnotes before it in document order, as `footnoteNumbers` already
   computes. The browser test is `packages/element/e2e/fe-135-footnote.spec.ts`.

6. **The count of skipped preserved atoms is a core method, not a field of `FindState` (FE-139
   criterion 4).** `FindState` is published to every consumer and its shape is checked exactly by
   existing tests, so the count is `DocumentCore.skippedPreservedFind()`. Tested in
   `packages/engine/test/fe-139-find-count.test.ts`. A view that shows the count reads the method
   when it renders the find panel.

## Not decided here

- Keyboard keys for zoom in, zoom out and reset (FE-138 criterion 4): UX and root decision. Decision 4
  takes Tab and Enter only; a shortcut is still open.

- Whether turning off a variant removes its header and footer stories (owner or spec decision).
- Whether a copy of a document keeps the variant stories' identifiers (SYN decision).

## Round 5 (2026-11-13)

7. **A preserved atom shows its label as "Kind, from Word, not editable here".** The kind is the atom's `label` with its first letter capitalised, as the spec's example gives it (FE-139 criterion 1). The text names the source because preserved content comes only from DOCX import (ADR 0017). The accessible name holds the caption and the fallback text (FE-139 criterion 3). No `style` attribute is set, because the strict policy forbids it (02 §3); the display size is left to a CSS rule of the element, so criterion 1 stays open. Tested in `packages/engine/src/fe-139-preserved-render.universal.test.ts`.

8. **Deleting a referenced target is refused, silently, in the core (FE-134 criterion 4).** I4 (03 §8) forbids leaving a reference unresolved, so a local transaction that removes a `node:`, `bookmark:` or `eq:` target while a remaining `ref` field names it is refused whole. Remote and internal transactions pass, because the authority decides those. The refusal does not yet explain itself or offer the references: that is the view's (FE-133 criterion 4). Tested in `packages/engine/test/fe-134-referenced-target.test.ts` and `packages/engine/test/fe-134-core-target-delete.test.ts`. An `eq:<label>` target resolves, as the model's validator resolves it, to an `equation_block` whose `label` is `<label>`; changing that label while a `ref` names it is refused too (fixer round 5, 2026-11-13). `style:` and `field:` targets belong to `styleRef` and `formValue`, not to `ref`, and are not checked here.

Not decided here: whether the explanation for a refused deletion is a message, a dialog or the references panel (UX decision).

## Round 6 (2026-11-13): FE-135 criterion 5, FE-140 criterion 3

Status: proposed. Decisions the spec leaves open, taken here by the spec's default or the smallest reading, for the main session to confirm.

1. A page or column break is shown as a visible, non-editable label, `Page break` or `Column break`, with `role="separator"` (`breakMarkDOM` in `packages/engine/src/schema.ts`). The spec says only "marked without pretending to show pages" (02 §7). The wording of the labels is a copy decision for PRM or UX; the line break stays `<br>` and the section break stays its `hr`.
2. A citation is a note whose accessible name is `Citation:` followed by the source identifiers in order (`citationLabel` in `packages/engine/src/schema.ts`). The node holds identifiers only; the source titles live in the definitions, which the view cannot read. The view shows the citation's `cached` text when it has one, and `[citation]` otherwise. Reading source titles needs the view to receive the definitions, which is not decided here.

## Round 8 (2026-11-14): FE-141 criterion 1 (fixed size), FE-139 criterion 2 (copy and cut)

Status: proposed. Taken by the smallest reading, for the main session to confirm.

1. The placeholder for a hidden region has one fixed block size, 2.5em with border-box sizing, one line, hidden overflow and a cut-off title (`.de-hidden-region` in `packages/element/src/styles/element.css`). The spec says "a fixed-size placeholder" (ADR 0019, FE-141) and gives no size, so the value is a proposed reading and not a design token. The UX owner may change the value; the test reads the shipped rule, so a change needs no test edit.
2. A whole-atom copy keeps the preserved atom and its fallback text in the clipboard payload. The read of ADR 0019 and SR-C2 allows preserved content to be copied within the same document (`packages/engine/test/fe-139-atom-copy.test.ts`). Whether the authority then accepts the paste elsewhere is the authority's and is not tested here.
