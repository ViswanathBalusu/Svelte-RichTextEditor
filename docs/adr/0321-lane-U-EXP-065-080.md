# ADR 0321: lane U-EXP-065-080 decisions (proposed)

Status: proposed. Date: 2026-11-13. Owner decisions stay the owner's; each point below uses the spec default.

## Context

Lane U-EXP-065-080 closes the criteria of EXP-065 to EXP-079 that earlier rounds left open for want of a container, a database or a browser. Podman works on this machine and the worker image `localhost/docedit-export-worker:s4` exists.

## Points decided by the spec default

1. **Image digest in the result manifest (EXP-076 criterion 4).** The result manifest records `image.id`, the Podman image ID, which is a sha256 content digest of the image. The registry digest of the base image is not recorded there. The spec default is read as this ID. Owner to confirm, or to ask for the registry digest as well.
2. **Same-host reproducibility (EXP-076 criterion 2).** Two compiles on one host were compared byte for byte (in `services/export-worker/src/exp-076-pdf-content.test.ts`). The criterion asks for different hosts, which this lane cannot run; it stays open.
3. **Readiness flake.** The shared readiness probe in `services/export-worker/src/sandbox-ready.ts` sometimes reports Podman unavailable or the sandbox as not starting when many agents share the 2 GiB Podman machine. Tests then skip rather than fail. Not changed here: the probe is not in this lane's files. A test run from the repository root reported Podman as unavailable where the same test run from `services/export-worker` passed.
4. **Exports schema (EXP-067 criterion 1).** The check reads the published DEP OpenAPI document. The raw-log route (EXP-066) is not built in this lane.

## Not decided here

- Whether a non-requester `view`, `comment`, `suggest` or `fill` caller should be refused the raw log with `forbidden` (EXP-066 criterion 2), or be given a separate log route. This needs a control-plane change in `services/document-service` and the owner's view of the route shape.
- The sandbox technology (EXP-069) and the TeX read restriction (EXP-075 criterion 1, the engine reads image files outside the work directory).
