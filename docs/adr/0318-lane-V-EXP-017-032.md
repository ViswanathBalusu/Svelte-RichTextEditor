# ADR 0318: Lane V-EXP-017-032, export stories round 2

Status: proposed. Owner: the export-latex package. Date: 2026-11-13.

## Context

Lane V-EXP-017-032 closes the criteria of EXP-017 to EXP-032 that were blocked on a compile, a container or a browser. In this round it handled EXP-023 (criterion 4), EXP-026 (criterion 5, partly) and EXP-020 (criterion 2, examined and not changed).

## Open questions and the default taken

1. EXP-026 criterion 5 says that fallback fonts "render with ligatures off". This lane reads that as TeX ligatures off, which is what 09 §3.2 ("Text ligature conventions") says: the class sets `Ligatures=TeXOff` on every family and `-tlig` on each fallback face. A test that isolates the fallback face's setting needs a character only the fallback covers, inside a TeX ligature sequence. The image's font manifest has no such pair (the chain is the math face, and its `--` and backticks are also in the families). The criterion stays unticked. Default taken: none changed; the owner may want a fallback face in the image manifest for this check.

2. EXP-020 criterion 2 (paragraph borders and shading). `\DEshade` in `packages/export-latex/class/docedit.cls` is an empty macro, and the class has no border macro. A drawing method (a background behind each paragraph's lines, a frame around them) is a class change and needs its own compile test. Default taken: not changed in this round. The class version is not bumped (ADR 0115).

3. EXP-023 criterion 4 is ticked on the job result of a preview (`converged: false`, diagnostic `preview_one_pass`, which names the table of contents and references). The test uses a fake compile. The real-compile check is in `services/export-worker/test/export.e2e.test.ts` and was not run in this lane.

## Decision

No product behaviour changed. One compile test was added (`packages/export-latex/src/exp-026-fallback.compile.test.ts`), and it passed in the Podman sandbox.

## Consequences

EXP-020 criterion 2 and EXP-026 criterion 5 remain open, with the reasons above in the story Notes.

## Round 3 (2026-11-14): EXP-028 criterion 3

Story worked: EXP-028 (in the range EXP-017 to EXP-032 that were not handled in earlier rounds). The rest of the range was checked: EXP-017, EXP-019, EXP-024, EXP-027 and EXP-031 have every criterion ticked, and the other stories with unticked criteria (EXP-018, EXP-020 to EXP-023, EXP-025, EXP-026, EXP-029, EXP-030, EXP-032) are in earlier-round lists and were not redone.

Added `packages/export-latex/src/exp-028-caption-label.compile.test.ts`. It compiles two captions with a `seq` field in the Podman sandbox and reads `FIRSTCAP Figure 1` and `SECONDCAP Figure 2` from `pdftotext -raw`. It passed.

Environment note: on the WSL Podman machine the sandbox does not start with the default cgroup settings (`crun: controller pids is not available`), so the sandbox probe reports "not ready" and compile tests skip. The test ran with `DOCEDIT_CONTAINER_CGROUPS=disabled` and `DOCEDIT_REQUIRE_SANDBOX=1`. The shared container settings are in `infra/test-env.ps1`.

Open question, not decided here: whether `align` on a figure moves its caption (the EXP-028 criterion 3 `align` half). Default taken: unchanged, `align` moves the picture line only, as the code does now. The owner decides (ADR 0223, decision 12). EXP-028 criterion 3 stays unticked for this reason.
