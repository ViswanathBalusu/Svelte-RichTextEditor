# 0268. Open questions from the SYN-001 to SYN-014 lane (round 1)

**Status:** proposed (2026-11-13). Lists questions the spec leaves open or that conflict with a story. It decides nothing; the owner or FRW/PRO decide.

**Context.** The lane reviewed the authority stories SYN-001 to SYN-014 in `docs/stories/SYN-sync-engine.md`. Their unticked criteria depend on work not built yet (workflow, transient authority, PostgreSQL storage, the client engine) or on a decision below. No criterion was ticked in this round, and no code changed.

## Questions

1. **Wrong-type field value code (SYN-012 criterion 5, SYN-003 open code).** The story expects `invalid_op` for a wrongly typed value (I15). `12 §4.2 P7` and `04 §5` (step 6 table) give `field_invalid`. `packages/authority/src/invariants.ts` gives `field_invalid` when the only violations are wrongly typed `value` paths. Default taken: the spec (`field_invalid`); the story criterion stays unticked. Owner: FRW to confirm.
2. **Code for a zero-step commit, a disallowed step type or unparseable steps (SYN-003).** The spec names no code. The room uses `too_large` for the step count and `invalid_op` for the rest. Default taken: as implemented. Owner: the spec (04 §5).
3. **Reserved origins from a client (SYN-003).** The room refuses `restore`, `import`, `migration`, `repair`, `sign`, `rules`, `prefill` and `control` with `invalid_op`. The spec does not say. Default taken: as implemented. Owner: PRO.
4. **Limits from `welcome` (SYN-003 criterion 6).** Nothing in `packages/authority` builds the `welcome`, so no test links the room's limits to the announced limits. Default taken: criterion unticked until the gateway that announces `welcome` has a test. Owner: BE/PRO.
5. **Client half of a control commit (SYN-004 criterion 2).** `packages/engine/src/sync` does not handle kind `control`. Default taken: the client half belongs to SYN-019 and stays unticked.
6. **Conformance kit contents (SYN-002 criterion 5).** The kit image copies `packages/authority/fixtures` but not `spec/`, so the generated schema artifact named by the engine file is missing from the image. Default taken: unticked. Owner: PRO-111 and the kit's Containerfile, which lies outside this lane.

## Consequences

Each question above has its own Note in the story file. Nothing else changes until the owners answer.
