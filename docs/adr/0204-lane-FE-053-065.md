# ADR 0204: Decisions of lane FE-053-065 (round 2)

Status: proposed. Recorded by the element and engine developers of lane FE-053-065. The owner decides
whether to accept them; each is the spec's default or a stated proposal, as noted.

## 1. Font alias format (FE-061)

The alias of a font file is the prefix `de-font-` followed by the file's full lowercase SHA-256 hex
digest. The spec (02 §3, §6) asks for an alias derived from the hash and does not give a format.
Proposed: the full digest, so that two different files never share an alias.

## 2. Duplicate check against the font set (FE-061)

A file is not added to the page's font set when a face with its alias is already in the set. The
check reads the set's own faces, not module state, so two versions of the editor share one alias.
The spec does not state the mechanism; this is the proposal.

## 3. Default view (FE-065)

05 §8.1 does not state the default of `view`. Proposed: `web` when the attribute is absent or has an
unknown value, and a touch device always gets the web view (FE-113). `view="print"` without the page
view falls back to the web view (02 §7, read as "fallback").

## 4. Opening a story panel by rights (FE-056 criterion 6)

The spec allows the sub-editor to open read-only or the command to be disabled. Chosen: the core
opens no panel for a person whose access does not let them change the story (`canEdit` on
`story:<id>` is false), and `openStory` returns `false`. A read-only panel needs the view, so it is
not built. The footnote panel has no such check yet.

## 5. Open items left for later rounds

- Whether the default family for a family with no manifest entry is `Liberation Sans` or another
  face (FE-062; the import default in `packages/export-docx/src/font-substitution.ts` is a
  candidate, not decided here).
- Whether the element's built-in substitution list must match the export-docx list by a shared
  file (FE-062 criterion 4).

## 6. Face choice for a family with several faces (FE-062, proposed)

Each manifest file is registered under its own hash alias (FE-061), so a family with several faces
has several aliases. Proposed: the lookup in `packages/element/src/font-family-lookup.ts` picks the
face with style `normal` and weight `400`, otherwise the first face in manifest order. The rule is
a proposal; the spec does not state it, and the engine does not use it yet.

## 7. Round 8 review of the open criteria (lane FE-053-065, 2026-11-13)

No criterion was ticked in this round. Each open criterion below needs something that is not
headless, not in this lane's packages, or not decided. Owner decisions are listed as questions.

- FE-053 criterion 3 (placeholder removed, reason shown): the placeholder is the shell's. The
  engine returns `{ ok: false, reason: 'upload-failed', message }` (`packages/engine/src/image-paste.ts`).
- FE-055 criteria 1 to 3: no drag handler in the engine view, no element `print()`, and no shell
  message path for a refusal. Criterion 4 needs the element's `print()` to read the session's access.
- FE-056 criterion 1: the `SubEditor` constructor (`packages/engine/src/subeditor.ts`) needs a DOM
  mount; the engine's Node.js setup has no DOM, and no DOM test environment is installed.
- FE-057 criterion 1: the panel's variant tabs are the view's. The core gives `variantsInUse` and
  `storyOfVariant`. Criteria 4 and 5 are the view's (focus, a remote edit shown in a panel).
- FE-058 criterion 1: the core names the new footnote as the panel target; mounting the sub-editor
  on it needs the DOM.
- FE-060 criterion 3: the skipped-matches message is the shell's. Criterion 5 needs suggestion mode
  (FE-041), and the Open questions do not decide its rule.
- FE-061 criterion 4 (second half): the editing surface refers to fonts only by alias. Not built
  (FE-062).
- FE-062 criterion 1: `fontFamilyValue` in `packages/engine/src/view-support.ts` does not call
  `familyAlias`. The engine is another lane's package. Criteria 2 and 3 need a substitute table,
  which the manifest does not carry (BE-047). Criterion 4 needs the LaTeX worker's font file.
  Question for the owner: where the substitute table lives (manifest field or a shared file).
- FE-063: the layout browser worker (`packages/layout/src/fe-076-browser-worker.ts`) registers no
  aliases. Its tests need a browser run, which was not started here.
- FE-064 criterion 2: `measure.test.ts` shows that a new epoch misses the cache, but nothing
  advances the epoch when a font loads. Criteria 1 and 3 need the layout pass to wait for fonts
  and to re-measure per block. The owner of the epoch source is not named in PLAN-1b.
- FE-065 criterion 4 and the rest: `doc-editor.ts` does not call `selectView`, so the element does
  not render the chosen view and does not throw on `print` without a page view.
