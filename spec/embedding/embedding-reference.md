# Embedding reference of `<doc-editor>`

Embedding API version 0.1 (major 0: not frozen), release 0.0.0. Generated by `packages/ui/scripts/generate.ts` from `packages/element/src` and the command registry; never edited by hand. The integration guide (`apps/reference-host/docs/integration-guide.md`) explains how to use it. All names are working names (SPK-007).

## Attributes

Set on the element in markup or with `setAttribute`. Changing one reconciles the editor (02 section 2.1).

- `doc-id`
- `endpoint`
- `mode`
- `view`
- `locale`
- `theme`
- `toolbar`
- `header`
- `keep-alive`

## Properties and methods

| Name | Kind | Access | Type or signature | What it does |
|---|---|---|---|---|
| `static version` | property | read | `string` | The embedding API version (05 §8), separate from the protocol version. |
| `static release` | property | read | `string` | The release of this package (FE-001; ADR 0039). |
| `static observedAttributes` | property | read | `string[]` |  |
| `getToken` | property | read/write | `GetToken \| null` | Called with `{ docId }` at start and when the token must be renewed. |
| `backend` | property | read/write | `Backend \| null` | Any implementation of the backend ports (05 §8.3); `endpoint` is then ignored. |
| `config` | property | read/write | `DocEditorConfig` | The configuration as the host set it; unknown keys are ignored (PRO-081). |
| `resolveUsers` | property | read/write | `ResolveUsers \| null` | Names and avatars from the host's directory (PRO-080); read whenever the shell asks. |
| `searchPrincipals` | property | read/write | `SearchPrincipals \| null` | Users and groups for the grants dialog and mentions (PRO-080), which arrive in phase 1b. |
| `strings` | property | read/write | `StringOverrides \| null` | The host's replacement strings by key (UX-063). A key the host omits falls back to the source table; a key no table knows is reported to the console. |
| `icons` | property | read/write | `IconOverrides \| null` | The host's replacement icons by the command's icon name (UX-063): SVG path data, or a drawing ({ paths, viewBox?, fill? }). An icon the host omits, or gives as anything but path data, keeps the built-in drawing. Icons are shown once the host gives a set (an empty object asks for the built-in drawings alone); without one, commands show labels only. Icons are drawn by the shell and never inserted as markup. |
| `extensions` | property | read/write | `readonly unknown[]` | Host-registered extensions (13 §7, 05 §8.1). A change while the shell is mounted is applied at once (UX-050). |
| `headerState` | property | read | `HeaderState \| null` | What a host-drawn header shows, as it is now (UX-014 criterion 5; proposed, ADR 0361): the connection and save state of `de-status`, and the details of `de-mode-change`, `de-presence` and `de-counts`. Null until the editor is live. Read-only: identifiers, states and counts, no content and no token. |
| `load` | method | call | `load(docId?: string): void` | Loads `docId` as if `doc-id` had changed; without an argument, or with the current one, reloads the current document (PRO-076). |
| `focus` | method | call | `focus(options?: FocusOptions): void` | Moves keyboard focus into the editing surface, with its last selection (FE-013; PRO-076). |
| `flush` | method | call | `flush(opts?: { timeoutMs?: number }): Promise<void>` | Resolves when nothing is in flight or queued; rejects at `timeoutMs` with the number of unconfirmed commits (PRO-083). With no document loaded nothing can be unconfirmed. |
| `getContent` | method | call | `getContent(): Promise<ConfirmedContent>` | The confirmed document with its `seq` (PRO-084). Rejects when no document is loaded. |
| `exec` | method | call | `exec(command: CommandName \| (string & {}), args?: CommandArgs): boolean` | Runs a command through the path the toolbar uses; false when it does not apply, is unknown or no document is loaded (PRO-085). `command` is an identifier of the command registry such as `format.bold` (UX-005), or a name of the editing core such as `bold`. |
| `queryCommand` | method | call | `queryCommand(command: CommandName \| (string & {}), args?: CommandArgs): CommandState` | Whether a command is enabled and active for the user's access now (PRO-085). |
| `nextField` | method | call | `nextField(): boolean` | Moves focus to the next field the user may fill, after the one that last had focus (the first when none had). False when no field took focus, and with no document loaded (FRW-069). |
| `focusField` | method | call | `focusField(key: string): boolean` | Moves focus to the field with `key`. For a key no field has it throws nothing and answers false, as it does with no document loaded (FRW-069). |
| `getFieldValues` | method | call | `getFieldValues(): Record<string, unknown>` | The values of the form fields by key, as the document holds them now (FRW-069). |
| `setFieldValue` | method | call | `setFieldValue(key: string, value: unknown): Promise<FieldFillOutcome>` | Fills the field with `key` as the current user, as typing into its control does; the server's permissions apply. Resolves with `{ ok: true, confirmed }`, or `{ ok: false, code, message }` with `permission_denied`, `field_invalid`, `conflict` or `not_found`; it does not reject (FRW-069). |
| `validateFields` | method | call | `validateFields(): FieldReport[]` | The fields that are required and empty, or whose entry has a problem, in document order, with keys and reasons. It changes nothing (FRW-069). |
| `getSelectionContent` | method | call | `getSelectionContent(): CdmFragment \| null` | The selection as a CDM fragment (PRO-084); null when no document is loaded. |
| `insertContent` | method | call | `insertContent(fragment: CdmFragment): InsertResult` | Inserts a CDM fragment at the selection through the same guards as typing (PRO-084). Nothing changes unless the result is `ok`; the result says why when it is not. |
| `print` | method | call | `print(): Promise<PrintOutcome>` | Prints the typeset PDF of the loaded document (02 §9.8; FE-073). When the access lists `no-print`, nothing is requested and nothing is printed, and the outcome says why (FE-055; UX-040 criterion 3). Otherwise the export job runs and its PDF is printed through a hidden frame. Both print modules load on first use, so neither is on the connect-time path (FE-119). |
| `requestExport` | method | call | `requestExport(options: ExportRequest): Promise<{ jobId: string }>` | Starts an export job of the loaded document and resolves `{ jobId }` (PRO-086). Refused when no document is loaded or the backend has no exports port (src/export.ts). The job's reports raise `de-export-progress`, `de-export-completed` or `de-export-failed` while the session that started it is still the current one (PRO-086). |
| `destroy` | method | call | `destroy(): void` | Unmounts the shell, destroys the editing core, closes the channel and the backend and stops every timer of the element; nothing more is raised (02 §2.1; PRO-076). Connecting the element again, or calling `load()`, starts afresh (ADR 0039). |

The standard custom element reactions (`connectedCallback`, `connectedMoveCallback`, `disconnectedCallback`, `attributeChangedCallback`) are called by the browser, not by a host.

## Events

Raised on the element as `CustomEvent`s that bubble and are composed; `detail` is the type shown.

| Event | Detail | When |
|---|---|---|
| `de-ready` | `{ docId: string; seq: number }` | The document is loaded and the editor is live (PRO-074). |
| `de-status` | `StatusDetail` | Connection or save state changed; at most once per animation frame (FE-007). |
| `de-change` | `{ seq: number }` | Changes were confirmed up to `seq`; at most once per interval (PRO-087). |
| `de-permission-change` | `Access` | The access of the open channel, first from `ch.opened`, then from every `perm.changed` (PRO-088). |
| `de-auth-required` | `{ docId: string; code: ErrorCode }` | `getToken` failed or the server refused the token (PRO-075). Carries no token. |
| `de-recovered-edits` | `{ count: number }` | Rejected or unsent content was set aside; `count` is the number of pieces (05 §8.1). |
| `de-share-request` | `{ docId: string }` | The owner asked for sharing, which the host owns (PRO-089; 13 §5). Identifiers only: the host opens its own dialog, and the editor shows none of its own. Nothing listens and nothing breaks when the host has no listener. |
| `de-access-request` | `{ docId: string; scope: string }` | A reader asked for access to hidden content (UX-104, ADR 0019). `scope` is the DEP scope identifier of the placeholder. The host decides who answers; the editor sends nothing itself. |
| `de-export-progress` | `{ jobId: string; state: string; progress: number \| null }` | An export job reports its state (PRO-086): identifiers and job state only, no content. |
| `de-export-completed` | `{ jobId: string; state: string; progress: number \| null }` | The export job completed (PRO-086). Same detail as `de-export-progress`. |
| `de-export-failed` | `{ jobId: string; state: string; progress: number \| null }` | The export job failed or was cancelled (PRO-086). Same detail as `de-export-progress`. |
| `de-selection` | `SelectionDetail` | The selection moved to another scope or block (05 §8.1; FE-028). Identifiers only, no content. |
| `de-command-state` | `{ commands: CommandStateChange[] }` | The commands whose `enabled` or `active` state changed, and only those (FE-028). |
| `de-mode-change` | `ModeChangeDetail` | The mode in effect, or the mode asked for, changed; also raised once when the editor is live (UX-014 criterion 5; proposed, ADR 0361). |
| `de-presence` | `PresenceDetail` | The other sessions this reader may see changed; also raised once when the editor is live (UX-014; ADR 0361). |
| `de-counts` | `CountsDetail` | The counts of the header's buttons changed; also raised once when the editor is live (UX-014; ADR 0361). |
| `de-field-change` | `FieldChangeDetail` | This person changed the entry of a form field (12 §10; FRW-070). It carries no value. |
| `de-fill-progress` | `FillProgressDetail` | The progress the guided bar of fill mode shows changed (12 §10; FRW-070). |
| `de-error` | `ErrorDetail` |  |

## Configuration

The `config` property. Keys the component does not know are ignored, and a value of the wrong type leaves the default (05 section 8.1).

| Key | Type | Default | What it does |
|---|---|---|---|
| `styleNonce` | string | none | Nonce for the <style> element the component creates when constructable stylesheets fail (02 section 3). Absent by default; an empty string counts as absent. |
| `graceMs` | number | `30000` | Grace period before a disconnected editor destroys itself, in milliseconds (02 section 2.1). Default 30,000. A negative or non-finite value is ignored. |
| `pdfViewerUrl` | string | none | URL of the PDF viewer's page (FE-071). Default: viewer/pdf-viewer.html next to the module. Absent by default; an empty string counts as absent. |
| `katexFontsUrl` | string | none | The directory, ending in a slash, that the host serves KaTeX's .woff2 files from (FE-069). The editor registers them under hash aliases. Absent by default: no KaTeX font is registered; an empty string counts as absent. |
| `selectionShim` | "instance" \| "library" | `"instance"` | Where the shadow root's getSelection comes from (02 section 8; spike S1 section 4.7). instance defines it on the editor's own root; library lets ProseMirror patch ShadowRoot.prototype. |
| `footnoteModel` | "inline" \| "paragraph" | `"paragraph"` | Experimental, for spike evidence only: the footnote content model (03 section 13; CDM-001). paragraph is the CDM's footnote content; inline is the spike's option A. |
| `deferRemoteWhileComposing` | boolean | `true` | Experimental, for spike evidence only: defer remote commits while the user composes text (input method). |
| `forceStyleFallback` | boolean | `false` | Experimental, for spike evidence only: use the nonce <style> element even where constructable stylesheets work. |
| `pageGuides` | boolean | `false` | Draws page guides in the web view where the last completed export's layout.json started a page (02 section 7; FE-068). Off by default; a guide is exact only at block starts and drifts between compiles. |
